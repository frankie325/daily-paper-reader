## 摘要
RGB-热红外（RGBT）目标检测通过利用可见光纹理与热红外线索的互补优势，能够在复杂场景中实现鲁棒感知。然而，现有方法主要依赖在全分辨率特征上进行密集跨模态交互，不可避免地引入背景干扰，并阻碍目标相关表示的学习。本文提出了原型超图融合网络（ProtoHGF-Net），一种将跨模态融合重新定义为原型级语义交互而非密集跨模态交互范式的新框架。具体而言，我们设计了原型超图融合，在紧凑的原型级语义空间中执行跨模态交互，从而在目标相关原型之间实现更具选择性的融合。为支持这种原型级融合，我们提出了教师-掩码校准蒸馏，在融合前利用模态专属教师和目标感知掩码对各模态特征进行校准。该策略抑制背景主导响应，并生成更聚焦于目标的特征。在DroneVehicle、DVTOD和FLIR上的大量实验表明，ProtoHGF-Net达到了最优性能，mAP50分别为85.9%、88.2%和79.1%。代码可在 https://github.com/ZiMo-Chen/ProtoHGF 获取。

## Abstract
RGB-Thermal (RGBT) object detection enables robust perception in complex scenes by leveraging the complementary strengths of visible textures and thermal cues. However, existing methods mainly rely on dense cross-modal interactions over full-resolution features, which inevitably introduce background interference and hinder the learning of target-relevant representations. In this paper, we propose the Prototype HyperGraph Fusion Network (ProtoHGF-Net), a novel framework that redefines cross-modal fusion as prototype-level semantic interaction rather than the dense cross-modal interaction paradigm. Specifically, we design Prototype HyperGraph Fusion to perform cross-modal interaction in a compact prototype-level semantic space. This design enables more selective fusion among target-relevant prototypes. To support this prototype-level fusion, we propose Teacher-Mask Calibration Distillation, which calibrates modality features before fusion using modality-specific teachers and target-aware masks. This strategy suppresses backgrou- nd-dominant responses and produces more target-focused features. Extensive experiments on DroneVehicle, DVTOD, and FLIR demonstrate that ProtoHGF-Net achieves state-of-the-art performance with 85.9\% $mAP_{50}$, 88.2\% $mAP_{50}$, and 79.1\% $mAP_{50}$, respectively. Our code is available at \href{https://github.com/ZiMo-Chen/ProtoHGF}{GitHub}.

## 1. 核心问题与整体含义

- **研究背景**：RGB-热红外（RGBT）目标检测通过结合可见光纹理和热红外热辐射线索，能够在低光照、遮挡、复杂背景等场景中实现鲁棒感知，广泛应用于无人机巡检、夜间交通监控和应急响应等。
- **现有局限**：
  - 主流方法依赖**全分辨率特征图上的密集跨模态交互**。这种密集交互假设所有空间位置和模态响应都应参与融合，但真实场景中目标区域通常占比很小，大量背景响应被不加区分地传播，导致背景耦合、跨模态干扰以及目标相关特征被削弱。
  - 现有蒸馏范式通常使用**融合后的多模态教师**进行监督。但教师特征本身可能仍包含强背景响应，蒸馏时可能将背景主导信息传递给学生，尤其在背景复杂、目标弱或模态质量不均衡时问题加剧。
- **整体含义**：ProtoHGF-Net 重新定义跨模态融合为**原型级语义交互**，先通过教师-掩码校准抑制背景，再在紧凑的原型语义空间中实现选择性融合，从而减少背景干扰并更有效地利用 RGB-Thermal 互补性。

## 2. 方法论

### 2.1 总体框架

- 基于 **YOLOv8 双分支检测器** 作为学生模型。
- 使用两个 **冻结的单模态教师模型**：RGB-only 检测器和 Thermal-only 检测器。
- 主要包含两个模块：
  - **ProtoHG-Fusion**：在原型级语义空间进行跨模态融合。
  - **TM-Calib**：在融合前对每个模态进行目标感知校准蒸馏。

### 2.2 原型超图融合（ProtoHG-Fusion）

- **原型提取**：
  - 对每个模态特征 \(F_r, F_t \in \mathbb{R}^{C\times H\times W}\)，使用卷积块生成 \(K\) 个注意力图（默认 \(K=6\)），并在空间维度做 softmax。
  - 通过空间加权求和将全图压缩为 \(K\) 个 \(C\) 维原型向量，得到 \(P_r, P_t \in \mathbb{R}^{K\times C}\)。
  - 该操作将 \(H\times W\) 个空间位置压缩为 \(K\) 个语义节点，显著降低后续关系建模规模。
- **超图构建与传播**：
  - 将两个模态的原型拼接为 \(X=[P_r;P_t]\in\mathbb{R}^{2K\times C}\)。
  - 构建联合关系矩阵 \(H\in\mathbb{R}^{2K\times 2K}\)，包含四个分块：
    - **模态内连接** \(H_{rr}\)、\(H_{tt}\)：基于余弦相似度的 KNN 硬连接（\(k_{intra}=3\)），并保留自环。
    - **跨模态连接** \(H_{rt}\)、\(H_{tr}\)：基于相似度 top-k 选择（\(k_{cross}=3\)），且 \(H_{tr}=(H_{rt})^\top\)，保证双向连接。
  - 关系矩阵采用 **硬 0/1 连接**，施加强结构先验并限制传播范围，缓解噪声累积和过平滑。
  - 采用“顶点→超边→顶点”的两步传播，使用归一化均值聚合；再通过残差连接得到更新后的原型 \(\tilde{X}=X+X'\)。
- **原型超图引导融合**：
  - 将传播后的原型展平并经过线性投影，生成通道级调制参数 \(\gamma_m,\beta_m\)。
  - 对原始全分辨率特征图进行通道调制：\(\hat{F}_m = F_m \odot (1+\gamma_m)+\beta_m\)。
  - 最后使用轻量全局门控融合：对调制后的 RGB 和 Thermal 特征分别做全局平均池化，经过 MLP 和 softmax 预测两个模态的标量权重，再线性加权得到 \(F_{fused}\)。
  - 相比像素级门控，全局门控更稳定，能自适应选择主导模态并避免局部噪声引起的排序扰动。

### 2.3 教师-掩码校准蒸馏（TM-Calib）

- **教师-掩码引导分解**：
  - 对每个模态的教师特征 \(F_T^m\)，计算通道注意力 \(A_c^m\) 和空间注意力 \(A_{sg}^m\)，并通过 1×1 细化网络融合后裁剪到 \([0,1]\)，得到联合通道-空间掩码 \(A^m\)。
  - 使用 \(A^m\) 将教师和学生特征分解为前景 \(F_{fg}\) 和背景 \(F_{bg}\) 分量：
    - \(F_{fg} = A^m \odot F\)
    - \(F_{bg} = F - F_{fg}\)
- **前景对齐蒸馏**：
  - 在目标区域内加权对齐学生前景特征与教师前景特征，采用加权平方误差损失。
  - 区域权重 \(W^m\) 强调教师响应更可靠的目标区域，减少边界、遮挡或低置信度区域对梯度的影响。
- **背景抑制蒸馏**：
  - 利用空间背景权重 \((1-A_{sg}^m)\) 对学生背景特征的能量进行抑制，降低背景误检。
- **前景-背景解耦正则化**：
  - 计算学生前景与背景特征之间的余弦相似度作为正交性正则，促使前景和背景子空间分离，避免背景模式泄漏到前景。
- **整体损失**：
  - TM-Calib 对 RGB 和 Thermal 两个模态分别计算前景对齐、背景抑制和正交正则损失，权重默认 \(\lambda_{fg}=1.0,\lambda_{bg}=2.0,\lambda_{orth}=0.07\)。
  - 最终损失为检测损失与 TM-Calib 损失之和：\(\mathcal{L}=\mathcal{L}_{det}+\mathcal{L}_{tmcalib}\)。
