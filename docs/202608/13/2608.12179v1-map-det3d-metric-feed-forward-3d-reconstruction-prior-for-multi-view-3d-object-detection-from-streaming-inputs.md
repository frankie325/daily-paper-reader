## 摘要
度量三维目标检测是具身智能体的核心能力，然而大多数可靠系统依赖深度传感器，牺牲了成本、功耗和集成简洁性。这推动了单目三维检测的发展，避免了额外约束，但它面临一个主要障碍：从单张图像中，深度，尤其是绝对尺度，是欠约束的。因此，普遍采用的先在二维中检测再预测三维属性的模式往往很脆弱，因为适度的距离误差就可能主导三维定位，而且学习到的尺度先验在相机、运动或环境发生域偏移时可能失效。为了解决这一问题，我们提出了 Map-Det3D，这是一种在线多视角三维目标检测模型，将检测直接引入由 RGB 重建的三维空间。我们将一个短时间窗口映射到多个视图，并将一个前馈度量三维重建模型重新用作几何主干，同时调整其目标感知能力。基于这一表示，Map-Det3D 直接在度量三维空间中预测边界框，无需广泛使用的二维到三维提升过程。在不同基准上的实验表明，这种设计支持强大的在线性能和无适配的鲁棒迁移，表明为检测训练重建先验是从单目视频实现稳定度量三维检测的实用途径。代码和模型可在 https://royyang0714.github.io/Map-Det3D 获取。

## Abstract
Metric 3D object detection is a core capability for embodied agents, yet most reliable systems lean on depth sensors, trading away cost, power, and integration simplicity. This motivates monocular 3D detection, which avoids additional constraints, yet it faces a major obstacle: from a single image, depth, and especially absolute scale, are underconstrained. As a result, the prevailing pattern of detecting in 2D and then predicting 3D attributes is often brittle, since modest range errors can dominate 3D localization, and the learned scale prior can fail when cameras, motion, or environments undergo domain shifts. To address this, we propose Map-Det3D, an online multi-view 3D object detection model that brings detection directly into a 3D space reconstructed from RGB. We map a short temporal window into multiple views and repurpose a feed-forward metric 3D reconstruction model as our geometric backbone while tuning its object-aware capabilities. Building on this representation, Map-Det3D directly predicts boxes in metric 3D space, without the widely used 2D-to-3D lifting. Experiments across different benchmarks show that this design supports strong online performance and robust transfer without adaptation, suggesting that training reconstruction priors for detection is a practical route to stable metric 3D detection from monocular video. Code and models are available at https://royyang0714.github.io/Map-Det3D.

- **研究背景**：三维目标检测（3DOD）对具身智能、自主导航、AR 等应用至关重要。当前可靠系统大多依赖 LiDAR 或 RGB-D 深度传感器，但存在成本高、功耗大、集成困难等实际限制。
- **核心问题**：纯图像（单目）3D 检测面临根本性困难——深度和绝对尺度从单张 RGB 图像中不可唯一确定；主流“先 2D 检测、再预测 3D 属性”的范式在相机内参、运动模式或场景统计发生域偏移时容易失效，小深度误差会显著放大 3D 定位误差。
- **整体含义**：论文提出 Map-Det3D，将前馈度量 3D 重建（FF3R）先验注入检测器，直接从多视图 RGB 中在度量 3D 空间预测目标框，绕过脆弱的 2D-to-3D 提升过程，从而在无深度传感器条件下实现更稳定、更可迁移的在线 3D 检测。

## 2. 论文提出的方法论

- **总体架构**：
  - 将长度为 \(T\) 的滑动时间窗口视为多视图输入，使用 MapAnything（一种前馈度量 3D 重建模型）作为检测 Transformer 的几何编码器。
  - 编码器输出多尺度特征图 \(\mathcal{F}=\{F_E,F_7,F_{11},F_{15}\}\) 以及每窗口尺度因子 \(\rho\)；尺度因子由可学习 scale token 经 MLP 解码得到。
  - 在每个时间步 \(t\)，仅对当前帧输出若干 3D 有向边界框，满足在线因果推断。

- **检测 Transformer**：
  - 将各视图特征按 patch 拼接并投影到 256 维，形成图像 token 序列 \(Q_{IMG}\)。
  - 通过密集 2D anchor 提议选择 top-\(M\) 参考点，生成初始 object queries \(Q_0\)。
  - 使用 \(L\) 层可变形 DETR 解码器迭代细化 queries，并更新二维参考框 \(B_{2D}\)，用于注意力采样和训练匹配。

- **Up-to-scale 3D 边界框头（关键创新）**：
  - 每个解码层输出一组边界框，回归不带尺度（up-to-scale）的 3D 属性：
    - 中心：回归 \(\tilde{x},\tilde{y}\) 和对数深度 \(\tilde{d}\)，恢复为 \(x=\rho \tilde{x}, y=\rho \tilde{y}, z=\rho \exp(\tilde{d})\)。
    - 尺寸：回归对数尺寸 \(\tilde{s}_w,\tilde{s}_l,\tilde{s}_h\)，恢复为 \(w=\rho \exp(\tilde{s}_w)\) 等。
    - 方向：回归连续 6D 旋转表示（allocentric），再基于预测中心方向转为 egocentric；不假设框为重力对齐。
    - 置信度：二值 objectness logit 经 sigmoid 得到 \(\sigma\)。
  - 所有几何属性都以尺度因子 \(\rho\) 从 up-to-scale 转换到真实米制单位。

- **相机条件与在线设置**：
  - 多模态编码器可以输入相机内参 \(K\) 和外参 \(P\)；当缺失时由骨干内部估计。
  - 推理使用滑动窗口（\(T\) 帧），仅输出当前帧检测；训练时随机采样 1～\(T\) 个视图，并随机采样帧率以强化鲁棒性。

- **训练损失**：
  - 使用匈牙利匹配基于辅助 2D 框进行正负样本匹配；2D 损失包括 focal loss 和 L1+GIoU。
  - 3D 损失采用解耦角点损失（disentangled corner loss）：分别用预测的某一属性与 GT 其他属性构造 8 个角点，计算 \(L_{xy}, L_z, L_{dim}, L_{rot}\)；旋转损失用 Chamfer 距离处理对称性，其余用 L1。
  - 对编码器提议层和所有解码层施加深度监督。
