## 摘要
开放世界目标检测要求模型能够识别已知类别、拒绝不熟悉的对象，并随时间纳入新类别。这在数据稀缺的场景（如生物医学和科学影像）中尤其具有挑战性，因为这些场景中稀有类别可能只有少量标注样本，且细粒度类别之间仅存在细微形态差异。基于原型的检测器自然适合这种情况，但它们通常将类别原型学习为独立的锚点，忽略了类别之间的关系结构。我们提出类别几何监督（CGS），一个通用框架，约束学习到的原型或类别表示空间以保留从训练数据中估计的视觉或语义类别不相似性。CGS引入了一个保持不相似性的目标函数，在保留标准任务损失的同时，使学习到的类别表示之间的成对距离与目标类别几何矩阵对齐。我们在原型识别、少样本生物医学目标检测、开放集检测、新类别插入以及COCO上的开放世界目标检测（OWOD）适应中实例化了相同的目标函数。实验表明，CGS提高了识别和ova检测的样本效率，显著增强了新类别插入能力，并在COCO上提高了未知类别召回率，同时保留了大部分已知类别的检测性能。消融实验表明，有意义的视觉几何提供了最可靠的增益，而随机几何有助于新类别分离但在少样本检测中一致性较差。这些结果表明，关系型类别几何是在有限监督下构建校准良好且可扩展的开放世界检测器的有效监督信号。

## Abstract
Open-world object detection requires models to recognize known categories, reject unfamiliar objects, and incorporate new classes over time. This is especially challenging in scarce-data settings such as biomedical and scientific imaging, where rare categories may have only a few annotated examples and fine-grained classes differ by subtle morphology. Prototype-based detectors are natural for this regime, but they typically learn class prototypes as independent anchors, ignoring relational structure among classes. We propose class-geometry supervision (CGS), a general framework that constrains learned prototype or class-representation spaces to preserve visual or semantic class dissimilarities estimated from training data. CGS introduces a dissimilarity-preserving objective that aligns pairwise distances among learned class representations with a target class-geometry matrix while retaining the standard task loss. We instantiate the same objective across prototype recognition, few-shot biomedical object detection, open-set detection, novel-class insertion, and OWOD adaptation on COCO. Experiments show that CGS improves sample efficiency in recognition and ova detection, substantially strengthens novel-class insertion, and improves unknown recall on COCO while retaining much of the known-class detection performance. Ablations show that meaningful visual geometry provides the most reliable gains, while random geometry can help novel separation but is less consistent for few-shot detection. These results suggest that relational class geometry is an effective supervisory signal for building calibrated and extensible open-world detectors under limited supervision.

## 1. 论文的核心问题与整体含义

- **研究问题**：开放世界目标检测（OWOD）需要同时完成已知类别识别、未知对象拒识和新类别逐步纳入。在生物医学、科学影像等**稀缺数据场景**下，这一问题尤为困难：稀有类别可能只有少量标注样本，细粒度类别之间仅存在细微形态差异。
- **现有方法的不足**：基于原型的检测器天然适合少样本场景，但通常将每个类别的原型视为**独立锚点**，仅通过任务损失驱动学习，忽略了类别之间的**关系结构**（哪些类别视觉/语义上相近或相远）。这会导致原型空间在开放世界决策中校准不良，尤其影响未知拒识和新类别插入。
- **论文核心思想**：提出利用**类别几何（class geometry）** 作为额外监督信号，约束学习到的类别表示空间保持类别间的不相似性关系，从而构建更校准、可扩展的开放世界检测器。

## 2. 方法论

### 2.1 问题建模

- 设当前已知类别集合为 \(C^t\)，未知类别为 \(U^t\)。每个已知类别 \(c\) 有一个小规模支持集 \(S_c\)，从中计算类别原型 \(p_c\)。
- 查询区域特征 \(z\) 通过最近原型距离进行分类；与所有已知原型距离都过大的区域被判为未知。
- 标准原型学习仅优化任务损失，导致原型空间欠约束。

### 2.2 类别几何监督（CGS）

- **目标几何矩阵 \(D\)**：编码类别间视觉或语义不相似性。
  - **视觉几何 \(D^{vis}\)**：利用支持区域裁剪图像的平均像素级 MSE 差异（公式 1），捕捉粗粒度形态关系。
  - **文本几何 \(D^{txt}\)**：利用类别视觉描述的文本嵌入余弦距离（\(1-\cos(e_i,e_j)\)）。
- **学习到的原型距离矩阵 \(G\)**：条目 \(G_{ij}=d(p_i,p_j)\)，使用欧氏或余弦距离。
- **标准化**：对 \(D\) 和 \(G\) 的非对角元素分别进行 z-score 标准化，得到 \(\hat D\)、\(\hat G\)。
- **类几何损失 \(L_{CG}\)**（公式 2）：
  \[
  L_{CG} = \frac{1}{|E|}\sum_{(i,j)\in E} (\hat G_{ij} - \hat D_{ij})^2
  \]
  其中 \(E\) 为所有类别对。
- **总损失**：\(L = L_{task} + \lambda L_{CG}\)，其中 \(L_{task}\) 为原有识别/检测损失，\(\lambda\) 控制几何监督强度。

### 2.3 理论性质

- **命题 1（图失真界）**：若 \(L_{CG}\le\epsilon\)，则学习原型图与目标类几何图之间的平均绝对失真不超过 \(\sqrt{\epsilon}\)。说明损失直接控制平均图失真。
- **命题 2（邻域顺序保持）**：若目标几何中类别 \(j\) 比 \(k\) 更接近 \(i\) 且边际为 \(\gamma\)，当学习到的成对距离失真小于 \(\gamma/2\) 时，原型空间保持该邻域关系。这为新类别有序插入提供了理论依据。

### 2.4 算法流程

- 给定支持集、特征提取器和目标矩阵 \(D\)。
- 每个训练 episode/小批次：
  1. 计算各类别原型；
  2. 构造原型距离矩阵 \(G\)；
  3. 标准化 \(D\) 和 \(G\)；
  4. 计算 \(L_{CG}\)；
  5. 更新参数最小化 \(L_{task}+\lambda L_{CG}\)。
- 推理时使用最近原型距离进行预测和未知拒识；新类别插入时仅添加新原型并扩展几何矩阵。

## 3. 实验设计

- **场景一：原型识别**
  - 数据集：寄生卵（parasitic ova）基准（Trehan et al. 2026）。
  - 模型：ProtoNet 风格，主干为 Wide ResNet，episode 采样 16 类、每类支持样本 \(K\in\{5,10,15,20\}\)、查询样本 5 个。
  - 对比：标准 ProtoNet vs. ProtoNet + CGS。
  - 指标：宏观 F1。

- **场景二：少样本生物医学目标检测**
  - 数据集：同一寄生卵数据集，15 个已知类 / 5 个保留类。
  - 模型：基于 DETR 的 FSP-DETR（Trehan et al. 2026）作为主基线；加入 CGS 后不改变检测器骨干。
  - 对比：通用检测器 DETR、YOLO、Stable-DINO、FCOS；原型/少样本基线 ProtoNet+SS、ProtoKD+SS；FSP-DETR 与 FSP-DETR+CGS。
  - 指标：5-shot、10-shot 检测 mAP；开放集检测 mAP/mAR。

- **场景三：新类别插入**
  - 在同一 ova 数据集上，将保留类别逐步插入已有原型空间。
  - 三个子设置：novel-only（仅评估新类）、generalized novel（所有原型可用但只看新类）、seen retention（插入后旧类性能保留）。
  - 对比：ProtoNet+SS、ProtoKD+SS、FSP-DETR、FSP-DETR+CGS。

- **场景四：COCO OWOD 标准协议**
  - 遵循 OW-DETR 的 Task 1–4 协议。
  - 两种适应模式：
    1. **冻结头部适应**：固定 OW-DETR 特征，仅微调轻量分类 MLP 头部，加入 CGS；
    2. **全模型微调**：端到端优化，将 CGS 加入标准 OW-DETR 训练目标。
  - 对比：ORE、UC-OWOD、Fast-OWDETR、OCPL、RE-OWOD、OW-DETR，以及两个 CGS 变体。
  - 指标：未知召回（U-Recall）、各任务已知类别 mAP（先前、当前、全部）。

- **消融实验**
  - 目标几何来源：无 CGS、随机几何 \(D^{rand}\)、文本几何 \(D^{txt}\)、视觉+文本、视觉几何 \(D^{vis}\)。
  - 评估 5-shot、10-shot 检测和 novel-only 插入表现。

## 6. 主要结论与发现

- **样本效率提升**：CGS 在原型识别和 ova 检测上均提升性能，且在最低样本量（5-shot）下增益最大。
- **开放集检测改善**：CGS 将 ova 开放集检测 mAP 从 0.045 提升至 0.061，说明结构化原型空间能改善未知拒识；mAR 略降，反映精度-召回权衡。
- **新类别插入大幅增强**：
  - novel-only mAP 从 0.0629 提升到 0.1558；
  - generalized novel mAP 从 0.0569 提升到 0.1348；
  - 同时旧类保留性能也有所提升。
- **COCO OWOD 上的权衡**：
  - 冻结头部 CGS 显著提高未知召回（Task 1–3），但已知类 mAP 下降；
  - 全模型微调能降低 mAP 损失，同时保留后期任务的未知召回增益。
  - 结果表明 CGS 提供了一个**可控的 mAP–U-Recall 权衡点**。
- **几何来源影响**：视觉几何最可靠；文本几何也有帮助；随机几何在 novel-only 插入中表现强，但缺乏一致性和可解释性。
- **核心观点**：关系型类别几何是在有限监督下构建校准、可扩展开放世界检测器的有效监督信号。

## 7. 优点

- **方法简洁通用**：只需一个成对距离对齐损失，可插入任意基于原型或类别表示的检测/识别框架，无需改变检测器架构。
- **理论支撑**：给出了图失真界和邻域顺序保持命题，为损失函数的效果提供了形式化解释。
- **多场景验证**：从识别到检测，从生物医学到 COCO，覆盖了开放世界检测的关键子任务（少样本、开放集、新类别插入）。
- **关注稀缺数据**：针对真实世界生物医学应用中标注极少的问题，具有实际意义。
- **消融分析扎实**：对比视觉、文本、随机几何的效果，明确指出“有意义几何”的重要性。
- **开放世界权衡讨论**：不仅报告性能提升，还明确讨论已知类 mAP 与未知召回之间的权衡，给出两种微调模式下的不同操作点。

## 8. 不足与局限

- **已知类性能损失**：在 COCO 冻结头部设置中，CGS 明显降低已知类 mAP（尤其后期任务），实际部署需权衡。
- **几何构造简单**：视觉几何基于像素级 MSE，可能无法捕捉细粒度形态或语义差异；文本几何依赖外部生成模型，质量受描述影响。
- **随机几何表现异常**：在 novel-only 插入中随机几何也能显著提升分离，说明部分增益可能来自“任意成对扩散”而非真正的类关系，需要更深入分析。
- **阈值依赖**：未知拒识阈值 \(\tau_{unk}\) 在验证集选择，实际场景中阈值泛化性未充分讨论。
- **COCO 对比有限**：未在 COCO 上与最新的开放词汇检测或更先进的 OWOD 方法进行严格少样本条件下的全面对比；Task 4 的某些指标（如 U-Recall）未在表中直接列出。
- **几何更新问题**：论文在“未来工作”中承认，当新类别到达且视觉与语义几何不一致时，如何可靠地学习/更新类别几何仍未解决。
- **实验覆盖**：主要集中于 ova 和 COCO，缺乏更多领域的跨数据集验证，泛化性仍需进一步检验。
