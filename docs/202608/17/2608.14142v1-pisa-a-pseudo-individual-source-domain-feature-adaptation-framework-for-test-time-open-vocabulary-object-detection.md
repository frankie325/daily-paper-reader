## 摘要
开放词汇目标检测测试时自适应（OVOD-TTA）旨在解决预训练基础模型在遇到图像域偏移时所遭受的性能下降问题。现有的无源域 OVOD-TTA 方法要么依赖细化的测试时信息进行重新评分，要么依赖伪标签进行自训练，当初始预测较差时会导致精度显著下降。同时，大多数传统源域估计方法恢复的是适合分类任务的抽象、稀疏表示，无法捕获检测所需的稠密、具体特征。为解决这些问题，我们提出 PISA，一种新颖的无源域 OVOD-TTA 方法，可无缝集成到开放词汇视觉主干中。该方法的核心组件包括损坏不变特征提取器（CIFE）、特征对齐模块（FAM）和多尺度对齐框架（BAA）。为捕获适合检测的特征，我们设计了 CIFE，利用 CLIP 视觉特征在损坏图像上的不变性，确保对各种损坏的鲁棒性。我们还开发了 FAM 和 BAA 用于预训练和自适应，以将损坏不变特征转换为接近原始源域特征的伪个体源域特征。这样，稠密且具体的伪个体源域特征被用作监督信号，而不是不可靠的伪标签信号。在三个基础模型上对受损坏的 VOC-C、COCO-C 和 LVIS-C 基准进行的实验表明，PISA 显著提高了原始模型的定位精度和类别识别准确率。值得注意的是，PISA 在无需访问源域数据的情况下达到了最先进的性能，在 COCO-C 上的 AP@50% 超过现有方法 3.92%。

## Abstract
Open-vocabulary object detection test-time adaptation (OVOD-TTA) aims to address the performance degradation that pre-trained base models suffer when encountering image-domain shifts. Existing source-free OVOD-TTA methods rely either on refined test-time information for re-scoring or on pseudo-labels for self-training, leading to significant accuracy degradation when initial predictions are poor. Meanwhile, most conventional source-domain estimation methods recover abstract, sparse representations suitable for the classification task, but fail to capture the dense, concrete features required for detection. To address these issues, we propose PISA, a novel source-free OVOD-TTA method that can be seamlessly integrated into open-vocabulary visual backbones. The core components of our method are the Corruption-Invariant Feature Extractor (CIFE), the Feature Alignment Module (FAM), and a multi-scale alignment framework (BAA). To capture detection-suitable features, we develop CIFE to exploit the invariance of CLIP's visual features across corrupted images, ensuring robustness against various corruptions. We further develop FAM and BAA for the pre-training and adaptation to transform the corruption-invariant features into pseudo-individual source-domain features that are close to the original source-domain features. In this way, dense and concrete pseudo-individual source-domain features are used for supervision instead of unreliable pseudo-label signals. Experiments on the corrupted VOC-C, COCO-C, and LVIS-C benchmarks across three base models demonstrate that PISA substantially improves both the localization precision and the category recognition accuracy of the original models. Notably, PISA achieves state-of-the-art performance without requiring access to source-domain data, surpassing existing methods by 3.92% in AP@50% on COCO-C.

  1. **依赖不可靠监督信号**：基于伪标签自训练或缓存特征重评分的方法在初始预测质量较差时，会累积错误并导致模型性能进一步退化。
  2. **源域特征估计不适合检测任务**：传统源域分布估计方法主要面向图像级分类，恢复的是抽象、稀疏的全局表示，无法满足目标检测所需的稠密、具体特征。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：
  - 利用 CLIP 视觉主干对图像损坏的固有鲁棒性，提取“损坏不变特征”。
  - 通过特征对齐模块和多尺度适配器，将损坏不变特征转换为“伪个体源域特征”，使其在特征空间中接近真实源域特征。
  - 在测试时，用这些伪源域特征作为监督信号，优化检测模型的少量可训练参数（BAA_a），避免使用不可靠的伪标签。

- **关键组件**：
  1. **损坏不变特征提取器（CIFE）**：
     - 采用 CLIP ResNet-50 视觉主干 stem 结构的第一层卷积和批归一化层。
     - 保留浅层特征，兼顾噪声鲁棒性和原始图像信息；不进行输入归一化，以避免放大损坏影响。
  2. **特征对齐模块（FAM）**：
     - 包含主分支和目标分支。
     - **主分支**：使用深度可分离卷积 + GELU + LayerNorm 进行空间下采样和通道投影；通过 Squeeze-and-Excitation（SE）注意力校准通道响应；残差捷径保证梯度稳定。
     - **目标分支**：引入 Mona 多尺度视觉适配器，并对卷积层施加谱归一化，增强对输入扰动的鲁棒性。
  3. **多尺度对齐框架（BAA）**：
     - **BAA_t**：插入骨干网络每层最后一个块，包含 Mona 适配器和维度调整模块；用于预训练阶段将 CIFE 特征逐步转换为伪源域特征。
     - **BAA_a**：插入每个块，是测试时唯一可训练的部分，用于在适应阶段微调原始骨干，其他组件冻结以保证稳定更新。

- **训练与适应流程**：
  - **预训练阶段**（两阶段）：
    - 使用干净图像 \(x_s\) 和增强图像 \(x_t\) 配对。
    - 第一阶段训练 FAM，使 \(f^\text{cife}\) 经 FAM 和骨干（不含 BAA_t）后的输出 \(f^s_l, f^t_l\) 与真实源域特征 \(f_l\) 对齐，损失函数：
      \[
      \mathcal{L}^1_{\text{FAM}} = \sum_{l=0}^{L} \left( |f^t_l - f_l| + |f^s_l - f_l| + \alpha |f^s_l - f^t_l| \right)
      \]
      其中 \(\alpha\) 防止特征差异过大（设为 10）。
    - 第二阶段冻结 FAM，仅训练 BAA_t，损失函数：
      \[
      \mathcal{L}^2_{\text{BAA}} = \sum_{l=1}^{L} |f^t_l - f_l|
      \]
  - **适应阶段（测试时）**：
    - 对于测试输入 \(x_{tta}\)，分别通过两条路径得到伪个体源域特征 \(f^p_l\)（经 CIFE + FAM + 骨干（含 BAA_t））和目标特征 \(f^{tta}_l\)（经原始骨干（含 BAA_a））。
    - 使用余弦相似度损失更新 BAA_a：
      \[
      \mathcal{L}_{TTA} = \sum_{l=1}^{L} \left( 1 - \frac{f^p_l \cdot f^{tta}_l}{\|f^p_l\|_2 \|f^{tta}_l\|_2} \right)
      \]
    - 更新后重新评估当前图像得到最终预测；每 \(T\) 个测试样本重置模型到初始状态，防止灾难性遗忘。

## 6. 论文的主要结论与发现

- PISA 在无需源域数据的情况下，显著提升了多个 OVOD 基线模型在损坏数据集上的定位精度和类别识别准确率。

- 消融实验表明：FAM 主分支、FAM 目标分支、BAA_t 和 BAA_a 相互补充，共同将 mAP 从 20.45% 提升至 23.06%（GDINO Swin-T 骨干，COCO-C）。

- 敏感性分析表明，较大的初始化间隔（如 \(T=\infty\)）通常能带来更高性能，且 PISA 始终优于无 TTA 的基线。

## 7. 优点：方法或实验设计上有哪些亮点

- **新颖的特征级监督范式**：用伪个体源域特征替代伪标签，从根本上避免低质量伪标签导致的错误累积，思路清晰且合理。
- **利用 CLIP 的损坏不变性**：CIFE 基于浅层 stem 结构提取既鲁棒又保留细节的特征，为检测任务提供了合适的表示，解决了传统源域估计不适合密集预测的问题。
- **模块化设计**：FAM 和 BAA 结构明确，主/目标分支、谱归一化、多尺度适配器等设计增强了鲁棒性和可训练性；BAA_a 作为唯一可训练模块，保证测试时更新稳定。
- **兼容性强**：PISA 可无缝集成到多种开放词汇视觉骨干（GLIP、GDINO、LLMDet），通用性突出。
- **实验充分**：跨三个数据集、多个基线、多种损坏类型，以及消融、敏感性、可视化分析，验证全面。
- **预训练成本较低**：仅需未标注图像和少量基础损坏类型，无需源域数据，符合 TTA 的实际约束。
