## 摘要
感知是自动驾驶系统的基础组成部分。尽管基于激光雷达的方法在目标检测方面取得了显著进展，但在恶劣天气条件下其可靠性可能会下降。雷达点云因其对恶劣天气和低光照场景的鲁棒性提供了一种可靠的替代方案。然而，雷达点云通常稀疏、无序且信息量低于激光雷达数据，这使得直接应用现有基于激光雷达的感知方法具有挑战性。为解决这些挑战，我们提出 IRGNN，一种用于雷达点云目标检测的不变性雷达图神经网络。IRGNN 首先利用平移和旋转不变的特征设计将雷达点云重建为图表示，从而能够对稀疏雷达测量进行鲁棒建模。随后，它采用一种改进的带有残差连接和虚拟节点层的消息传递神经网络（MPNN），以增强局部特征传播和全局上下文建模。最后，将任务特定的预测头应用于学习到的图表示，用于目标分类和边界框预测。在 RadarScenes 数据集上的实验结果表明，IRGNN 优于现有基于雷达的目标检测方法，并取得了有竞争力的性能。此外，IRGNN 显著降低了推理过程中的计算成本和内存占用，证明了其在自动驾驶中高效雷达感知的有效性和实际潜力。

## Abstract
Perception is a fundamental component of autonomous driving systems. While LiDAR-based methods have achieved remarkable progress in object detection, their reliability can degrade under adverse weather conditions. Radar point clouds provide a robust alternative due to their resilience to bad weather and low-illumination scenarios. However, radar point clouds are typically sparse, unordered, and less informative than LiDAR data, making it challenging to directly apply existing LiDAR-based perception methods. To address these challenges, we propose IRGNN, an Invariant Radar Graph Neural Network for radar point cloud object detection. IRGNN first reconstructs radar point clouds into graph representations using translation- and rotation-invariant feature designs, enabling robust modeling of sparse radar measurements. It then employs an improved message passing neural network (MPNN) with residual connections and a virtual node layer to enhance local feature propagation and global context modeling. Finally, task-specific heads are applied to the learned graph representations for object classification and bounding box prediction. Experimental results on the RadarScenes dataset show that IRGNN outperforms existing radar-based object detection methods and achieves competitive performance. In addition, IRGNN significantly reduces computational cost and memory usage during inference, demonstrating its effectiveness and practical potential for efficient radar-based perception in autonomous driving.

## 2. 论文提出的方法论

### 2.1 数据预处理与图构建

- **预处理流程**
  - 使用 RadarScenes 数据集中的 6 维特征：`x, y, vx, vy, timestamp, RCS`。
  - 由于多部雷达采集存在时间差，将 **0.5 秒内的雷达点云聚合为一帧**，并裁剪到车辆前方 **100 m × 100 m** 区域。
  - 删除坐标或速度无效的点。

- **图结构定义**
  - 将每个雷达点作为一个节点 $V_i$，节点特征为 $F_v$ 维。
  - 使用 **k 近邻（KNN）** 构图，$\sigma = 20$，边特征为 $F_e$ 维。
  - 边定义为 $E_{uv} = (V_u, V_v)$，其中 $V_v = KNN_{\sigma}(V_u)$。

### 2.2 平移不变性设计

- **问题**：原始坐标 $x, y$ 在平移后发生变化，若直接编码为节点特征则不具备平移不变性。
- **方案**：
  - 将绝对坐标 $x, y$ 转换为**相对坐标 $(dx, dy)$**，作为边特征。
  - 节点特征保留速度 $v_x, v_y$、RCS、时间索引 $t_{idx}$ 和连通性信息 $c$。
  - 边特征包含相对位置 $(dx, dy)$。
- **效果**：图表示在点云整体平移时保持不变。

### 2.3 旋转不变性设计：增强点对特征（EPPF）

- **问题**：旋转点云会改变速度和相对位置，破坏旋转不变性。
- **现有方法**：RadarGNN 使用点对特征，包括距离 $|d|$、速度夹角 $\theta_{\alpha}$、速度与边的夹角 $a_1, a_2$，但局部几何表达能力有限。
- **EPPF 方案**：
  - 为每个节点建立**局部参考系（LRF）**：
    - 计算邻域点的位移向量 $b_u = a_{i,u} - a_i$。
    - 根据距离加权得到权重 $w_u = \frac{\|b_u\|^{-1}}{\sum_{n=1}^{a} \|b_n\|^{-1}}$。
    - 构造加权协方差矩阵 $M_i = \sum_{n=1}^{a} w_n b_n b_n^{\top}$。
    - 对 $M_i$ 进行特征分解，取**最大特征值对应的特征向量**作为局部参考轴（LRA）。
  - **EPPF 特征**：
    - 节点间距离 $|d|$。
    - 速度与边的夹角 $a_0, a_1$。
    - 两个节点速度的夹角 $\theta_{\alpha}$。
    - LRA 与边的夹角 $\beta_0, \beta_1$。
    - 两个 LRA 之间的夹角 $\theta_{\beta}$。
  - 节点特征使用速度模长 $|v|$、RCS、时间索引、连通性信息。

- **意义**：EPPF 在保证旋转不变性的同时，增强了局部几何特征的判别力。

### 2.4 GNN 骨干网络

- **特征嵌入**
  - 节点和边特征首先通过多层感知机（MLP）进行维度扩展，节点特征升至 224 维，边特征升至 16 维。

- **虚拟节点层**
  - 在特征嵌入后加入一个可学习的虚拟节点 $VN_i$，其特征维度与首层节点特征对齐。
  - 将虚拟节点特征与原始节点特征相加：$\tilde{X}_i^{(1)} = X_i^{(1)} + VN_i$。
  - **作用**：为每个节点提供图级全局上下文，缓解稀疏雷达点云中局部观测不完整的问题。

- **消息传递神经网络（MPNN）**
  - **消息生成**：对每条边 $(i, j)$，利用目标节点特征 $F_{V_i}$、邻居节点特征 $F_{V_j}$、边特征 $F_{E_{ij}}$ 经 MLP 生成消息 $M_{ij}$。
  - **消息聚合**：对目标节点的所有邻居消息进行聚合 $M_i = \sum_{j \in N(i)} M_{ij}$。
  - **节点更新**：结合原始节点特征与聚合消息，经 MLP 更新节点特征 $F_{V_i} = \phi_u(F_{V_i}, M_i)$。

- **残差块**
  - 在每个 MPNN 层后加入残差连接，缓解深层图网络中的**过平滑**问题。
  - 若相邻层特征维度相同，则残差输出 $\hat{F}_i^l = \tilde{F}_i^l + \gamma F_i^{l-1}$；若维度不同，则使用线性投影 $p(l)$ 对齐。
  - 论文中设置残差缩放因子 $\gamma = 0.3$，后接批归一化和 ReLU 激活。

### 2.5 损失函数与后处理

- **损失函数**
  - 总损失 $L = \lambda_c L_{cls} + \lambda_b L_{bbox}$，其中 $\lambda_c = 1.0$，$\lambda_b = 0.5$。
  - **分类损失**：加权交叉熵损失，用于多类目标分类（包括 Car、Pedestrian、Pedestrian Group、Two-Wheeler、Large Vehicle、Background）。
  - **边界框损失**：Huber 损失，平滑阈值 $\delta = 1.0$，介于 L1 和 L2 之间，增强鲁棒性。

- **后处理**
  - 分类头输出类别分数，边界框头使用两层 MLP 预测候选框。
  - 去除背景类或背景置信度高的候选框。
  - 将相对坐标系下的框转换回绝对坐标系。
  - 在同一帧内应用**非极大值抑制（NMS）**去除重复检测。
  - 使用置信度阈值过滤低分框，得到最终结果。
