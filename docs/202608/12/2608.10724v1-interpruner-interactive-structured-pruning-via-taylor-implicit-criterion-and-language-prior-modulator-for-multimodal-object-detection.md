## 摘要
多模态目标检测在遥感中表现出有效性，尤其是RGB-红外范式。并行特征提取器为鲁棒检测提供了丰富的多模态信息，但也引入了大量的通道冗余和计算开销。现有剪枝方法虽能减少通道冗余，但它们专为单模态骨干网络设计，忽视了跨模态交互和动态场景级冗余。本文提出了InterPruner，这是首个面向RGB-红外目标检测器的交互式结构化通道剪枝框架。具体而言，我们首先推导出泰勒隐式准则（TIC），通过高阶泰勒展开和隐函数定理来量化通道重要性。然后，模态交互冗余分析器（MIRA）通过相互可补偿性评估识别冗余通道。最后，场景先验通道锚点（SPCA）利用语言先验作为语义锚点来衡量通道-场景相关性，以实现动态通道重要性估计。面向RGB-红外检测的跨模态通道剪枝尚未被探索。在RGB-红外目标检测数据集上的大量实验表明，InterPruner在性能几乎不下降的情况下保持了高检测性能。具体而言，在剪枝50%通道的情况下，它在FLIR数据集上的mAP甚至提高了0.6%。代码将在GitHub上提供，以促进未来的工作。

## Abstract
Multimodal object detection proves effective in remote sensing, especially the RGB-Infrared paradigm. The parallel feature extractors provide rich multimodal information for robust detection, yet introduce substantial channel redundancy and computational overhead. Existing pruning methods can reduce channel redundancy, but they are designed for unimodal backbones, overlooking cross-modal interactions and dynamic scene-wise redundancy. In this paper, we propose InterPruner, the first interactive structured channel pruning framework for RGB-infrared object detectors. Specifically, we first derive a Taylor-Implicit Criterion(TIC) to quantify channel importance via high-order Taylor expansion and the implicit function theorem. Then, a Modality Interaction Redundancy Analyzer (MIRA) identifies redundant channels via mutual compensability assessment. Finally, a Scene-Prior Channel Anchor (SPCA) uses language priors as semantic anchors to measure channel-scene relevance for dynamic channel importance estimation. Cross-modality channel pruning for RGB-Infrared detection is yet unexplored. Extensive experiments on RGB-infrared object detection dataset demonstrate that InterPruner maintains high performance with negligible degradation. Specifically, it even achieves a 0.6% mAP increase on the FLIR dataset when pruning 50% of the channels. Code will be available on GitHub to facilitate future work.

- **研究背景**：RGB–红外多模态目标检测在遥感、自动驾驶等场景中具有明显优势：RGB 提供纹理与语义，红外对光照不敏感，两者互补可提升鲁棒性。

- **现有方法局限**：现有通道剪枝方法主要面向**单模态 CNN 骨干网络**，将通道视为独立可裁剪单元，忽略了两个关键因素：
  - **跨模态耦合**：某一分支中被认为“不重要”的通道，可能对另一分支的表示有关键影响。
  - **场景动态冗余**：不同环境条件下冗余分布会变化，固定剪枝准则难以适应。
- **本文目标**：提出首个面向 RGB–红外目标检测器的**交互式结构化通道剪枝框架 InterPruner**，在保持检测性能的同时有效降低计算复杂度。

## 2. 方法论

InterPruner 由三个核心模块组成，分别处理通道贡献估计、跨模态冗余识别和场景自适应调制。

### 2.1 Taylor-Implicit Criterion（TIC，泰勒隐式准则）

- 目的是**近似通道移除后经过再训练的真实损失变化**，避免对每个通道进行完整微调。
- 定义两种损失变化：
  - 立即损失变化 \(\Delta L_{el}\)：剪枝后不更新参数时的损失增量。
  - 真实损失变化 \(\Delta L_{rl}\)：剪枝并完全再训练到收敛后的损失增量。
- 通过**泰勒展开**损失函数及其梯度，并利用**隐函数定理**将参数位移 \(\Delta W\) 展开为梯度 \(g\) 的幂级数，得到对“恢复损失”\(\Delta L_{rec}\) 的高阶近似：
  \[
  \Delta L_{rec} \approx -\frac{1}{2} g^\top H^{-1} g - \frac{1}{6} T(H^{-1}g, H^{-1}g, H^{-1}g)
  \]
- 最终通道重要性准则 \(C_q\) 结合直接可计算的立即损失与上述恢复损失估计。\(C_q\) 越小，通道越可剪。

### 2.2 Modality Interaction Redundancy Analyzer（MIRA，模态交互冗余分析器）

- 目的：识别**可被另一模态补偿的冗余通道**。
- 做法：交替**屏蔽整个 RGB 分支或红外分支**，仅对另一分支进行短时适应（\(B\) 步梯度更新），观察其损失变化。
- 引入连续门变量 \(z_q \in [0,1]\) 控制通道缩放，计算每个通道对损失的**方向导数** \(G_q\)：
  \[
  G_q(W) = \left\langle W_{m}^{(l,c)}, \frac{\partial L(W)}{\partial W_{m}^{(l,c)}} \right\rangle
  \]
- 对 \(B\) 个批次，度量 \(G_q\) 的变化 \(R_q\)。\(R_q\) 大说明该通道在对侧模态缺失时被“重新激活”，即原双流模型中其功能被抑制、可被补偿，因此应优先剪除。

### 2.3 Scene-Prior Channel Anchor（SPCA，场景先验通道锚点）

- 目的：使剪枝决策**根据图像场景动态调整**，而非全局固定。
- 实现：
  - 使用冻结的 **Qwen2.5-VL** 视觉语言模型，结合可学习软提示 \(P\)，为每对 RGB–红外图像生成结构化场景描述，包括光照、场景上下文、物体证据和热属性。
  - 用冻结的 **CLIP** 图像编码器提供模态差异监督，优化软提示，使提示对模态可靠性敏感。
  - 将生成的文本描述编码为 768 维语义向量 \(z_i\)。
  - 通过一个轻量级两层 **MLP** 将 \(z_i\) 映射为通道级调制权重，并做中心化、归一化，得到 \(w_{i,m,l,c} \in [1-\gamma, 1+\gamma]\)。
  - 在校准集上平均样本相关权重，得到固定通道权重，用于最终剪枝。

### 2.4 统一通道选择

- 最终重要性分数：
  \[
  S_{i,m,l,c} = \alpha C_{m,l,c} - \beta w_{i,m,l,c} R_{m,l,c}
  \]
  其中 \(C\) 为 TIC 贡献分数，\(R\) 为 MIRA 冗余分数，\(w\) 为 SPCA 场景权重，\(\alpha,\beta\) 为全局系数。
- 剪枝策略：
  - 预保护贡献最高的 10% 通道免于剪枝。
  - 在 RGB 和红外对应层中保持等宽裁剪，以维持融合模块结构兼容。
  - 使用全局贪心策略分配剪枝预算，直到满足目标比例。

## 3. 实验设计

- **数据集**：
  - **FLIR**：10,228 张户外道路场景图像（8,862 训练 / 1,366 测试），标注 Person、Car、Bicycle 三类，包含拥挤街道、尺度变化和杂乱背景。
  - **DroneVehicle**：56,878 张无人机航拍 RGB–红外图像对，五类车辆（Car、Truck、Bus、Van、Freight-Car），带旋转框标注，场景为小目标、高密度和复杂纹理。
- **基准模型**：预训练的 **C2DFF** 多模态检测器，基于 Ultralytics YOLOv8 框架。
- **评估指标**：mAP、mAP50、参数量（Params）和 FLOPs。
- **剪枝比例**：30%、50%、70%。
- **对比方法**：包括 ℓ1 Norm、Network Slimming、Intra-Fusion、BilevelPruning、REPrune、IRPruneDeXt、Probabilistic Pruning、CSP、HOT-MKS 等单模态剪枝或压缩方法。
- **训练/微调设置**：TIC 与 MIRA 进行 8 批次适应；SPCA 使用 16 个可学习令牌的 Qwen2.5-VL 提示，CLIP ViT-L/14 提供监督；剪枝后模型用 SGD 微调。

## 6. 主要结论与发现

- **跨模态剪枝存在明显必要性**：直接迁移单模态剪枝方法在 RGB–红外检测上性能退化，证明通道重要性是跨模态耦合且场景相关的。
- **InterPruner 性能突出**：在所有测试设置下基本优于对比方法；尤其在 **FLIR 上剪枝 50% 通道时 mAP 反而提升 0.6%**；在 DroneVehicle 上 70% 剪枝仍保持 79.0% mAP50。
- **高阶泰勒展开有效**：三阶泰勒-隐式准则优于一阶、二阶，说明高阶非线性建模对补偿感知剪枝有增益。
- **MIRA 与 SPCA 贡献显著**：MIRA 在高剪枝率下提升明显；SPCA 在 70% 剪枝时带来 5.5% mAP50 提升，证明场景自适应的重要性。
- **\(\beta/\alpha=1.0\) 最优且与剪枝率无关**：该比例在 30%/50%/70% 下均达到最佳，表明统一的权重设定具有鲁棒性。
