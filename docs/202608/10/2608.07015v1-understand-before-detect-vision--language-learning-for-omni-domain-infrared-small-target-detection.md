## 摘要
全领域红外小目标检测对红外监视至关重要，但由于成像域异构和目标特征不一致，仍面临挑战。以往基于深度学习的方法遵循纯视觉范式，在特定域任务上取得了良好性能。然而，现有方法采用任务特定的监督学习范式，将全场景红外观测简化为稀疏目标监督，丢弃了跨异构域保持不变的语义，导致域偏移下检测性能大幅下降。为解决此问题，我们提出“先理解后检测”范式，将全领域红外小目标检测表述为理解驱动的过程，即在精确检测之前先进行整体红外目标理解。基于此范式，我们提出JinSight，首先通过语言监督建立整体红外小目标理解，然后将学到的跨域表征迁移到精确小目标检测。通过将红外表征与语言语义关联，JinSight使单个模型能够泛化到异构红外域。我们还引入了潜在语义交互（LSI），在紧凑的低秩空间中交换与语言对齐的全局语义和细粒度空间特征。为解决多模态全领域红外小目标基准缺失问题，我们构建了OmniIRST-VL，这是首个用于全领域红外小目标检测的大规模、高多样性视觉-语言数据集。它包含超过39k个标注，涵盖六个互补指令任务，覆盖场景级理解和目标中心推理。

## Abstract
Omni-domain infrared small target (IRST) detection is crucial for infrared surveillance, yet remains challenging due to heterogeneous imaging domains and inconsistent target characteristics. Previous deep learning-based methods have been developed for visual-only paradigms and achieved promising performance on domain-specific tasks. However, existing methods follow the task-specific supervised learning paradigm. This paradigm simplifies the full-scene infrared observations to sparse target supervision, discarding the semantics that remain invariant across heterogeneous domains. Consequently, detection performance suffers substantially under domain shifts. To handle this issue, we introduce \textbf{``understand before detect''}, a paradigm that formulates omni-domain IRST detection as an understanding-driven process, where holistic infrared target understanding precedes precise detection. Building on this paradigm, we propose \textbf{JinSight}, which first develops holistic IRST understanding through language supervision and then transfers the learned cross-domain representations to precise small-target detection. By grounding infrared representations in language semantics, JinSight enables a single model to generalize across heterogeneous infrared domains. We then introduce Latent Semantic Interaction (LSI), which exchanges language-aligned global semantics with fine-grained spatial features in a compact low-rank space. To address the lack of multimodal omni-domain IRST benchmarks, we build \textbf{OmniIRST-VL}, the first large-scale, highly diverse vision--language dataset for omni-domain IRST detection. It comprises over 39k annotations across six complementary instruction tasks covering both scene-level understanding and target-centric reasoning.

    - 红外小目标检测在交通监控、自动驾驶和反无人机系统中至关重要。然而，在实际部署中，传感器跨越地基、空基、天基平台，覆盖近红外、短波红外、长波红外等多个光谱波段，观测场景从天空到海面差异巨大。

- **现有方法的局限性：丢弃了跨域不变的语义**
    - 现有深度学习模型（如CNN、Transformer架构）大多遵循**任务特定的监督学习范式**，将检测问题简化为像素级的**目标-背景二值预测**。
    - 这种**二值化简化**存在三个关键问题：
        1.  **域异构性坍塌**：不同域中多样的背景结构、杂波模式被统一压缩为单一的“背景”类别，忽略了其内在的域间差异。
        2.  **场景信息丢失**：丰富的全场景信息被压缩为粗略的二值标签，丢失了场景内容和目标-上下文关系。

    - 总体而言，现有范式**丢弃了跨异构域本应保持不变的语义信息**，导致在域偏移时检测性能大幅下降。

### 2. 论文提出的方法论：核心思想、关键技术细节

论文提出了 **JinSight** 框架，一个两阶段的视觉-语言模型，并构建了大规模数据集 **OmniIRST-VL**。

- **核心范式：“先理解后检测”**
    - **第一阶段：理解**。通过语言指令对生成式视觉语言模型（VLM）进行微调，任务包括场景描述、物理属性问答、目标计数和定位，使视觉编码器成为**红外小目标感知的通用表征骨干**，能捕捉场景上下文和目标语义。
    - **第二阶段：检测**。将第一阶段微调好的视觉编码器（ViT）迁移至密集预测任务（分割/检测），并设计专用模块来融合其全局语义和细粒度空间特征。

- **关键技术一：红外小目标导向的视觉指令微调**
    - 基于 **OmniIRST-VL** 数据集，对预训练的VLM进行指令微调。
    - **训练目标**：采用自回归语言建模损失，优化模型根据图像和指令生成正确回答的能力。
    - **作用机制**：背景导向任务（如描述、物理问答）监督背景和成像特性；目标导向任务（如计数、定位）要求编码器保留目标的空间证据。这些互补信号共同优化ViT，使其能**抑制背景杂波**的同时**保留弱目标响应**。
    - **实现效果**：
        - **语言引导的语义对齐**：通过共享的词汇表学习异构域的域不变表征。
        - **自回归监督**：要求编码器保留目标-场景关系的推理证据，补充了二值掩膜缺失的信息。

- **关键技术二：潜在语义交互**
    - **核心动机**：指令微调后的ViT提供判别性强的全局语义，但其输出的单尺度、块状（patchified）Token缺乏定位微小目标所需的精细空间细节。直接在高维空间进行融合效率低下。
    - **LSI模块设计**：在一个紧凑的低秩空间（维度 r ≪ D）中，高效地交换ViT的**全局语义Token**和多尺度主干网络提取的**细粒度空间特征**。
    - **交互流程**：
        - **空间到语义路径**：将局部空间细节注入全局语义Token。
        - **语义到空间路径**：将全局红外小目标语义传播回空间特征。
    - **公式化表示**：
        - 语义Token更新：\(\tilde V_i = V_i + \text{CrossAttn}(V_i, S_i, S_i)\)
        - 空间特征更新：\(\tilde S_i = S_i + \text{CrossAttn}(S_i, \tilde V_i, \tilde V_i)\)
    - *注：所有交互均通过低秩投影矩阵在低维空间完成。*
    - **最终效果**：融合后的特征被组织成特征金字塔，送入下游任务头（如UPerNet），实现精确检测。

- **基础设施建设：OmniIRST-VL 数据集**
    - 为支持此范式，构建了首个大规模、高多样性的全领域红外小目标视觉-语言基准。
    - **数据来源**：以WideIRSTD数据集（11000张图像）为视觉源，提取其元数据和目标标注。
    - **标注生成**：通过**元数据条件化的语言增强**技术，自动生成指令-回答对，然后经过自动质量过滤、红外专家独立审查和分歧仲裁。
    - **数据集特征**：
        - **规模**：超过**39,000**个图像-指令-回答对。
        - **任务覆盖**：涵盖**6个互补的指令任务**，分为两类：
            - **场景导向**：详细描述、物理属性问答（询问波段、平台等）。
            - **目标中心**：图像级和区域级的视觉计数、视觉定位。
        - **域覆盖**：全面覆盖地基、空基、天基平台，以及NIR、SWIR、LWIR波段，包含最大的≤10像素目标集合（7421个）。

### 6. 论文的主要结论与发现

- **范式有效性**：“先理解后检测”范式通过语言监督保留了完整的场景上下文和目标-上下文关系，能有效学习跨异构红外域的**可迁移表征**，显著优于传统的二值预测范式。
- **模型性能优越**：JinSight模型在**WideIRSTD基准**上，相比最先进方法，在IoU指标上取得了**超过14%的相对大幅提升**。
- **泛化能力强大**：在多个不同域偏移类型的外部数据集上，JinSight均一致性地取得了最高的检测概率（Pd）和IoU，证明了其强大且一致的泛化能力。
- **模块协同增益**：“红外视觉指令微调”和“潜在语义交互”两个核心组件协同工作，一个提供红外小目标感知的语义知识，一个高效地将这些语义传递到空间特征，两者相辅相成，缺一不可。
- **数据集价值**：构建的**OmniIRST-VL**数据集为全领域红外小目标理解提供了一个全面且必要的多模态基准，其互补的任务设计（场景+目标）对于学习鲁棒表征至关重要。

### 7. 优点

- **范式创新**：提出的“先理解后检测”思想深刻，从根本上改变了红外小目标检测的解决思路，从单纯的像素分类转变为语义理解驱动的过程。
- **方法设计优雅**：JinSight的两阶段设计清晰明确，特别是LSI模块，通过低秩空间高效地实现了异构模态（全局语义/局部空间）特征的交互，兼顾了性能和效率。
- **数据集贡献巨大**：OmniIRST-VL数据集填补了该领域多模态基准的空白，其规模大、域覆盖广、任务设计巧妙，为未来的多模态红外感知研究奠定了坚实基础。
- **实验扎实全面**：实验设计极为严谨，对比方法多且重训保证了公平性，消融实验从多个维度剖析了方法各组成部分的作用，跨域泛化评估有力地支撑了其主要结论。

### 8. 不足与局限

- **模型规模与效率**：JinSight模型（314M参数）相比一些轻量级方法（如ALCNet仅0.52M），在参数量上有显著增加。虽然通过LSI控制了计算量，但在算力资源有限的边缘设备上部署仍有挑战。文中仅在RTX 4090上进行了测试。
- **语言监督成本**：构建高质量指令数据集的流程复杂，需要自动生成、自动过滤和多轮专家人工审核，数据构建成本和专家资源的投入较高。
- **一阶段推理能力**：JinSight在推理时虽然仅需视觉输入，但其强性能依赖于第一阶段VLM的语言监督预训练。这增加了训练流程的复杂性和计算开销。
- **ViT骨干的固有局限**：尽管LSI缓解了ViT特征粗糙的问题，但方法根本上仍依赖ViT作为视觉骨干，其对极小目标的空间细节建模能力能否从本质上超越专门设计的CNN或混合架构，文中未做极限边界测试。
- **潜在偏差风险**：虽然OmniIRST-VL注重多样性，但任何数据集在场景、目标类型上的覆盖都可能存在未被完全平衡的偏差，可能导致模型在极端的、未见过的成像条件下性能下降。
