## 摘要
RGB-红外（RGB-IR）目标检测受益于互补的可见光与热辐射线索，但在光照变化、天气变化和杂乱场景下，有效融合仍具挑战。现有RGB-IR融合方法往往以表现力较强的图块级交互为代价，换取更轻量但更受限的适应机制。我们通过实验观察到，在成对的RGB-IR输入上，预训练的寄存器标记同时包含模态共享和模态特异性信息，这表明它们可作为跨模态通信的紧凑载体。基于这一观察，我们提出RegisterBridgeMM，一种由寄存器介导的融合框架，其结构为一个三阶段的寄存器生命周期：聚合保留预训练中继承的每模态寄存器摘要；桥接通过共识残差调节执行双向的寄存器到图块读取；投影则将生成的寄存器摘要转化为图块特征的空间自适应校准。该寄存器通路避免了密集的图块间跨模态交互，同时保留了预训练的图块表示。在两条骨干网络均冻结的情况下，RegisterBridgeMM在LLVIP、M3FD、DroneVehicle和FLIR-Aligned所有四个基准上，均取得了评估方法中最高的mAP50-95。

## Abstract
RGB-infrared (RGB-IR) object detection benefits from complementary visible and thermal cues, but effective fusion remains challenging under illumination changes, weather variation, and cluttered scenes. Existing RGB-IR fusion methods often trade expressive patch-level interaction for lighter but more constrained adaptation mechanisms. We empirically observe that pretrained register tokens contain both modality-shared and modality-specific information on paired RGB-IR inputs, suggesting that they can serve as a compact substrate for cross-modal communication. Building on this observation, we propose RegisterBridgeMM, a register-mediated fusion framework organized as a three-stage register lifecycle. Aggregate preserves per-modality register summarization inherited from pretraining; Bridge performs bidirectional register-to-patch reading with consensus-residual regulation; and Project translates the resulting register summary into spatially adaptive calibration of patch features. This register pathway avoids dense patch-to-patch cross-modal interaction while preserving the pretrained patch representation. With both backbone streams frozen, RegisterBridgeMM achieves the highest mAP50-95 among the evaluated methods on all four benchmarks: LLVIP, M3FD, DroneVehicle, and FLIR-Aligned.

- **核心问题**：RGB – 红外（RGB–IR）目标检测中，如何在光照、天气等剧烈变化下，高效地融合可见光与热成像的互补信息，同时避免现有方法在表现力与计算成本之间的两难。
- **整体含义**：提出一种全新的融合范式，即利用预训练 Vision Transformer（DINOv3）中的*寄存器标记（register tokens）*作为跨模态通信的紧凑载体，而不是在密集的图块级进行交互。这既能保持预训练图块表示的完整性，又能以极低的参数量和计算开销实现鲁棒融合，最终在多个基准上取得最优精度。

## 2. 方法论

**核心思想**：将寄存器标记的生命周期分为三个阶段——聚合（Aggregate）、桥接（Bridge）和投影（Project），且整个过程中双流 ViT 骨干网络完全冻结，仅训练少量桥接与校准模块。

### 2.1 阶段一：聚合（Aggregate）
- 使用两个独立且冻结的 DINOv3 ‑B 骨干分别处理 RGB 和红外图像。
- 骨干的前 2 层（L₀=2）不插入任何可学习模块，仅依靠预训练自注意力让寄存器标记从各自模态的图块中抽取全局摘要。
- 目的：保留预训练寄存器中已存在的**模态共享/模态特异性**结构（实验观察到 4 个寄存器中有 3 个高度对齐，1 个发散），不进行干预。

### 2.2 阶段二：桥接（Bridge）
桥接插入在浅层–中层（层 {2, 5, 8}），包含两个子模块：

#### RWPR（Register‑Write Patch‑Read）
- 在每个注入层 ℓ，用单头交叉注意力让一方的寄存器查询另一方的图块（图块仅作为 key 和 value，不被更新）。
- 数学形式：  
  ΔR = CA(ℓ)₍R→T₎​(r₍R,ℓ₎, p₍T,ℓ₎, p₍T,ℓ₎)  
  ΔT = CA(ℓ)₍T→R₎​(r₍T,ℓ₎, p₍R,ℓ₎, p₍R,ℓ₎)
- 通过可学习门控系数 α₍ℓ₎（初始化为 0.1）与 LayerNorm 结合残差更新寄存器：  
  r̃₍m,ℓ₎ = LN(r₍m,ℓ₎ + α₍ℓ₎Δ₍m₎)
- 复杂度 O(kND)，远低于图块间密集注意力的 O(N²)。

#### RCRS（Register‑Consensus / Residual‑Split）
- 将双向更新后的寄存器显式分解为两模态的共同部分（共识）和模态特定残差。
- 共识向量：c₍ℓ₎ = ½(r̃₍R,ℓ₎ + r̃₍T,ℓ₎)
- 重新混合：r′₍m,ℓ₎ = c₍ℓ₎ + β₍ℓ₎(r̃₍m,ℓ₎ − c₍ℓ₎)，其中 β₍ℓ₎∈(0,1) 是可学习的标量（初始 0.5），控制残差的保留程度。
- 输出寄存器 r′ 继续通过后续冻结的自注意力层，影响上层特征。

### 2.3 阶段三：投影（Project）
- 提取最深注入层 ℓ⋆ 的共识与残差，构成 CR 摘要向量 s_CR（拼接共识均值及两组残差的绝对值）。
- 通过 MLP 与线性投影生成全局仿射种子（seedₛ），同时用图块特征差（ˆFₛᴿ – ˆFₛᵀ）经过 1×1 卷积得到空间相异图（gapₛ）。
- 两者相加形成空间自适应调制场 fieldₛ，再通过零初始化仿射头生成逐位置的缩放 γ、偏移 β（SPADE 风格），以残差形式校准各模态的 FPN 特征。
- 校准后的特征金字塔逐级融合，送入 RT‑DETR 检测头。

## 6. 主要结论与发现
- 预训练 DINOv3 的寄存器标记自然形成“3+1”的模态共享/特异性结构，可以作为高效跨模态通信的基础。
- 寄存器介导的融合通路（RWPR + RCRS + MAC）以极低的参数开销（27.8 M 可训练参数），在四个不同特性的基准上均取得最高 mAP₅₀⁻₉₅。
- 冻结骨干不仅可以保留预训练表示的质量，甚至略微优于完全微调，凸显寄存器路径的潜力。
- 跨模态一致性‑残差分解（RCRS）和空间自适应调制（MAC）对最终精度有显著贡献。

## 7. 优点
- **思路新颖**：首次将 ViT 中的寄存器标记作为多模态融合的载体，改变了过去依赖图块密集交互的范式。
- **参数与计算高效**：仅训练少量桥模块，骨干冻结，交叉注意力复杂度为 O(kN)，明显低于 O(N²)。
- **模块化设计**：三阶段生命周期清晰，每阶段功能明确，且各模块可独立替换或消融。
- **实验坚实**：跨四个涵盖不同挑战的基准验证，消融详尽，定性分析辅助理解。
- **保留了预训练先验**：不破坏预训练 patch 表示，冻结带来的收益为迁移至小样本场景提供了可能。

## 8. 不足与局限
- **依赖特定预训练模型**：框架有效性与 DINOv3 的寄存器设置紧密相关，若更换无寄存器的骨干，方法无法直接迁移。
- **检测头单一**：仅在 RT‑DETR 上验证，是否对其他检测头（如 Anchor‑based 系列）同样有效未测试。
- **训练细节不透明**：未报告 GPU 数量、训练时长、batch size 等，复现和效率对比缺乏关键信息。
- **跨模态对齐假设**：假设输入图像已空间对齐，未处理未对齐的 RGB‑IR 图像对（实际应用中常见）。
- **模态缺失鲁棒性**：未讨论单模态失效或极端天气下的融合有效性，安全性考量不足。
