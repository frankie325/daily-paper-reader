# Abstract 

In this paper, we introduce SearchDet, a training-free long-tail object detection framework that significantly enhances open-vocabulary object detection performance. SearchDet retrieves a set of positive and negative images of an object to ground, embeds these images, and computes an input image–weighted query which is used to detect the desired concept in the image. Our proposed method is simple and training-free, yet achieves over 16.81% mAP improvement on ODinW and 59.85% mAP improvement on LVIS com-pared to state-of-the-art models such as GroundingDINO. We further show that our approach of basing object detec-tion on a set of Web-retrieved exemplars is stable with re-spect to variations in the exemplars, suggesting a path to-wards eliminating costly data annotation and training pro-cedures. 1

# 1. Introduction 

The proliferation of the web as a repository of image-text data has drastically improved access to data used to train neural object detection models. Modern deep-learning models rely heavily on this colossal cache of data to train and improve their representations. Such datasets are often used to pre-train vision-language models such as CLIP [31], GLIP [23], GroundingDINO [25], and T-Rex2 [13]. While models such as GroundingDINO and GLIP have achieved substantial advances in grounded object detection by reduc-ing the pre-train-to-downstream task discrepancy, further improving the performance of these models necessitates ei-ther continual pre-training or additional task-specific fine-tuning that incurs extra costs. A crucial aspect of the aforementioned models’ training involves data indexed by search engines like Google, which provide easy access to high-recall sets of images for a text query. # 2. Related Work 

## 2.1. Open-Vocabulary Object Detection 

Open-vocabulary object detection involves grounding text labels within an image using bounding boxes. Open-vocabulary object detection differs from standard object de-tection where any text label may be provided, while stan-dard object detection models detect a fixed set of classes. Existing open-vocabulary object detection models such as GroundingDINO [25], T-Rex2 [13], OWL-ViT [28], and GLIP [23] utilize advances in vision-language research to extend closed-vocabulary object detection to an open-vocabulary setting. They frequently utilize a form of con-trastive language-image pre-training [30], which pairs text captions with object regions embedded with pre-trained text and image models. While this allows for fast inference times and the flexibility of an open vocabulary, this kind of training is time-consuming and resource-intensive, re-quiring large amounts of paired image-text data to achieve strong object detection performance. By contrast, our method utilizes existing tools and re-quires no additional training . Specifically, we use pre-trained segmentation [17, 18, 32] and backbone models [26, 29] with web-based retrieval to achieve strong open vocabulary performance. The search engine used for im-age retrieval serves as an ever-expanding, perpetually im-proving link between the text and image modalities, a bot-tleneck that most open vocabulary detection models address only through further pre-training on larger amounts of data. 

## 2.2. Few-shot Object Detection 

Few-shot object detection (FSOD) [2] is the task of detect-ing an object in an image when provided a few exemplar images of a class. Such methods use techniques from the broader few-shot learning literature including using class prototypes [15, 35, 41] to represent the class to detect, and meta-learning [7, 38, 40] to train networks to adapt their parameters and representations from few examples. In our work, we utilize a set of support images to generate a “query embedding”, which can be regarded as a class prototype, to detect objects. Like prior FSOD works, our query embed-ding can be generated from as few as one support image. Unlike most prior works, however, our method involves no training of an object detection system and relies entirely on representations derived from a frozen image backbone. 

## 2.3. Image Segmentation 

Image segmentation is the task of grouping pixels of an in-put image into semantically coherent “segmented” parts. This differs from semantic segmentation, which requires classifying each image pixel into a set of predefined classes. SAM [18, 32] and its variants [17, 19] are the state-of-the-art in image segmentation, providing accurate segmented entities for an input image. In our work, we utilize the image regions output by SAM (HQ) to generate region proposals for object grounding lo-cations. This is akin to classical works in object detection which generate bounding box proposals before classifying and further refining their position [8, 33]. We perform no additional finetuning on SAM and use its output masks as proposals out of the box. 

# 3. SearchDet: Object Detection on Web Images 

SearchDet, our proposed object detection framework, is de-signed to accurately ground objects using web-retrieved im-ages. For a given (image, object label) pair, our method starts by retrieving positive support images corre-sponding to the object label, along with negative images to exclude from the image representation. We use these re-trieved images to independently generate a singular object “query” with an attention mechanism, to detects the image’s SAM regions containing the object and to localize the ob-ject with a similarity heatmap. An adaptive thresholding technique filters the SAM regions to extract those that most closely match the query. Finally, we take the intersection of the most highly ranked SAM regions and our similarity heatmap to output the final predictions outlined in Figure 2. ## 3.1. Web Retrieval of Exemplars 

In this section, we detail the process of retrieving positive and negative exemplars from the web for concept ground-ing, and how these examples are processed to improve de-tection accuracy. To detect the object label in the input image, we start by retrieving image exemplars of the ob-ject from the web. We utilize a search engine (in our case, Google) to download a set of images that represent the ob-ject of interest, both for positive and negative search query. The top ten images, empirically determined, from the search results are selected; without any other pre-processing and are passed to DINOv2 for embedding extraction. (described in §3.1.2). 

3.1.1. Necessity of Negatives 

Retrieved images for the main search query may contain secondary, associated objects in the background, making it challenging to isolate the object of interest. For exam-ple, many images of a surfboard retrieved from the web also contain water or waves, making it difficult to extract only the surfboard for our representation. We utilize “nega-tive queries” to isolate the target object from these common associations. For a given object label (the positive search query), we utilize a large language model, Microsoft Phi-3-mini-4k-instruct[1], to generate negative queries using in-context examples, such as “waves” for a surfboard or “food” for a fork 2.

## 3.2. SAM Region Proposals 

To generate region proposals for our object to ground, we turn to SAM models, which are trained to take a prompt, most commonly an image coordinate or bounding box, and generate the segmentation for the instance indicated by the prompt. These prompts can be applied in a uniform grid across images, segmenting images into a collection of high-quality object masks. By segmenting images in this way, we obtain region proposals demarcating the most prominent objects in the image. We then check the similarity between each of these region proposals and a query embedding rep-resenting the object to determine which regions contain the object to ground. To generate the query embedding, we em-bed the input image and all support images via DINOv2’s [29] CLS token. We use the same methodology, as de-scribed in subsubsection 3.1.2, to calculate the final query embeddings from all the support image embeddings. Next, we generate a region embedding [34] for each of the region proposals by masking the input image outside of the region, and then embedding this image using DINOv2’s CLS to-ken. We compute the cosine similarity between each region embedding and the query embeddings to obtain similarity scores, then filter these scores via the method of §3.2.1 to obtain a set of regions believed to contain the object. 15132 3.2.1. Grounding an object accurately poses significant chal-lenges, especially when relying solely on Euclidean dis-tances between given segmentation mask embeddings and embeddings of the input image query. Percentile or rank-based thresholding, often fail to adapt effectively to the unique distribution of distances in each image as distribu-tion of distances tends to be skewed leading to suboptimal mask selection. Empirical observations reveal that arbitrar-ily selecting a fixed number of masks with smallest dis-tances from the adjusted query embedding introduces a high rate of false positives. This issue becomes particularly pro-nounced when the concept may not be present in the image and invariably selecting a mask, compounds the problem of false positives. To address this limitation, we employ frequency-based adaptive thresholding, which dynamically adjusts the de-tection threshold based on the distribution of distances be-tween adjusted embeddings, qadjusted (as seen in Equation 4) and segmented masks. Let: • Q = {q1, q 2, . . . , q m} be the set of m adjusted query em-beddings (coming from our positive and negative query images). In this section, each qi ∈ Q is computed by directly subtracting the corresponding negative embed-ding from its positive counterpart, on a per-pair basis (i.e., without softmax weighting). • M = {M1, M 2, . . . , M n} be the set of n segmented masks, identified by SAM on our target image. • d(qi, M j ) be the Euclidean distance between the ith query embedding qi and the jth segmented mask Mj .• B = {b1, b 2, . . . , b n} be the set of data intervals or ’bins’ for creating distance distribution. • R = {rij | rij = d(qi, q j ), 1 ≤ i < j ≤ m} be the set of Euclidean distances between each pair of adjusted embeddings. We define this as the reference distance dis-tribution. • T be an empirically calculated acceptance threshold for selecting a candidate mask out of all segmented masks. The algorithm aims to identify and verify segmented masks from a target image that closely matches a set of adjusted query embeddings Q. It begins by computing the Euclidean distances Dij between each adjusted query’s em-bedding qi and each mask’s embedding Mj ∈ M generated by DINOv2. If a single mask constitutes more than T = 80% of a bin, it is selected as a candidate mask. We choose the 80% threshold empiri-cally as it consistently produces stable results. ## 3.3. Heatmap Generation 

While the Segment Anything Models typically generate high-quality object regions, they may fail to detect key ob-ject regions or may not accurately output objects of inter-est’ boundaries as seen in Figure 2, where the bounding box generated from a SAM region alone contains two cars. More generally, if we rely only on the SAM regions and the model fails to generate a region corresponding to the object of interest, then we are unable to ground the object accurately. Hence, following Blume et. al [3], we adopt a heatmap generation method to ground the object without re-liance on preexisting boundaries. To generate a heatmap of likely object locations, we independently embed the input image along with all positive and negative images to extract patch features. Each feature set is average-pooled to pro-duce a single embedding for each image. Using the same process described in subsubsection 3.1.2, the positive and negative image features are pooled into respective embed-dings. The final query embedding is obtained by subtracting the negative embedding from the positive embedding. The cosine similarity between this query embedding and upsam-pled patch features of the input image results in a heatmap of object locations. The heatmap values range from 0 to 100 and are subsequently binarized: values ≤ 50 are set to 0, and values > 50 are assigned 1. Empirical evaluation shows that a binarization threshold of 50 achieves strong performance in downstream tasks of joint object grounding. 

## 3.4. Joint Object Grounding 

We then calculate the intersection between each SAM mask and the binarized heatmap. Each region will output a single bounding box, as long as it has a nonempty intersection with the heatmap. If the mask is incomplete or inaccurate, the heatmap can provide complementary information (and vice versa) as illustrated in Figure 2. 

# 4. Experiments 

## 4.1. Datasets and Metrics 

We demonstrate the effectiveness of our method on four settings - the COCO detection benchmark [24], LVIS [9], OdinW [21], and Roboflow-100 [4]. We do not use the training datasets, as ours is a training-free method; instead, we focus on the COCO-2017-val split (80 classes), and the LVIS minival-version-1.0 (1203 classes), while using the full OdinW and Roboflow-100 validation splits. We use the class names as the positive search query, get the negative query name from an LLM call, and extract 10 positive and negative support images from the web for all datasets. We pass them to our method to get a precise mask which is compared to the ground truth. We compare our method to state-of-the-art open vocabulary object detection methods including GLIP [22], DINOv [20], Grounding Dino [25], and T-Rex2 [13]. DINOv and T-Rex2 are especially perti-nent, as they also require in-context images to perform ob-ject detection. We also test our method in a few-shot setting (10-shot) on the COCO 2014 dataset, and compare it against both baseline methods like Meta-RCNN and more sophisti-cated and recent techniques like the CrossTransformer [12].

This observation suggests that the LLM-based method to generate a negative class helps to retrieve images that are significantly differ-ent from their positive counterparts. We further observed that by downloading images on different days of the week, we would obtain different sets of images. However, these different image sets do not have a significant effect on per-formance. These results suggest that despite the dynamic nature of the web, the retrieved images are stable enough to achieve consistent performance.

# 5. Conclusion 

In this paper, we presented SearchDet, a training-free infer-ence stage framework that leverages web-retrieved images for long-tail open-vocabulary object detection. Our exper-iments demonstrate that SearchDet not only outperforms existing state-of-the-art models like GroundingDINO and GLIP-L, but also that SearchDet shows robustness against variations in exemplars used for object detection. While the performance of our method is proportional to the number of Web-retrieved images, even a single retrieved image is suffi-cient for strong performance.
