# Abstract 

Thermal object detection is a critical task in various fields, such as surveillance and autonomous driving. Current state-of-the-art (SOTA) models always leverage a prior Thermal-To-Visible (T2V) translation model to obtain vis-ible spectrum information, followed by a cross-modality aggregation module to fuse information from both modal-ities. However, this fusion approach does not fully exploit the complementary visible spectrum information beneficial for thermal detection. To address this issue, we propose a novel cross-modal fusion method called Pseudo Visible Feature Fine-Grained Fusion (PFGF). Specifically, a graph is constructed with nodes generated from multi-level ther-mal features and pseudo-visual latent features produced by the T2V model. Each level of features corresponds to a subgraph. An Inter-Mamba block is proposed to per-form cross-modality fusion between nodes at the lowest level; while a Cascade Knowledge Integration (CKI) strat-egy is used to fuse low-level fused information to high-level subgraphs in a cascade manner. After several iter-ations of graph node updating, each subgraph outputs an aggregated feature to the detection head respectively. Un-like previous cross-modal fusion methods, our approach explicitly models high-level relationships between cross-modal data, effectively fusing different granularity infor-mation. Experimental results demonstrate that our method achieves SOTA detection performance. Code is available at 

https://github.com/liting1018/PFGF .

How-ever, the generated thermal images may be unreliable, po-tentially degrading the performance of thermal pedestrian detectors. Another route is based on cross-modal transfer, which can be further divided into two approaches. The first approach, feature domain transformation [45], utilizes an auxiliary network to convert thermal features into visible ones. However, this process demands substantial computa-tion and large models to maintain feature quality in high-dimensional spaces. The second approach, image domain transformation [44], employs a generative model to directly convert thermal images into visible ones. The transformed visible images are then fused with the original thermal im-ages, as illustrated in Fig.1(a). While image domain transformation methods have at-tained the state-of-the-art performance in thermal object de-tection, they still face obstacles related to occlusions and visible image noise. This limitation primarily stems from the inherent unreliability of visible images generated from thermal data, which can introduce noise that adversely af-fects detection accuracy. Furthermore, these approaches of-ten neglect the fine-grained multimodal knowledge relation-ships between pseudo-visible and thermal data. As a result, effectively harnessing the complementary nature of thermal and visible information to resolve ambiguities in complex scenes remains a significant challenge. Fortunately, Graph Neural Networks (GNNs) offer a promising alternative for modeling and reasoning about relationships [30]. This mo-tivates us to utilize graph structures for enabling interactions among features at various granularities. Such an approach ensures comprehensive utilization of information between low-level features to high-level semantics, leading to richer and more nuanced cross-modal integration. However, the flexible flow of information between nodes may introduce redundancy or irrelevant data, potentially hindering detec-tion performance. To address this, we incorporate Mamba’s selection mechanism [53] to effectively filter out unimpor-tant information in the long-range context, which is partic-ularly crucial for thermal feature maps that often contain noise and lack texture details. Furthermore, by iteratively updating node features based on neighborhood nodes, it can minimize the impact of less relevant nodes, thereby enhanc-ing feature fusion and representation. Based on the above analysis, as illustrated in Fig. 1(b), we propose a novel cross-modal fusion method, dubbed as Pseudo Visible Feature Fine-Grained Fusion (PFGF). First, we obtain the visible features using the Pearl-GAN method [37], which are referred to as generative features. To fuse these generative features, we introduce the Graph-Mamba Fusion module. Specially, a graph is constructed that con-sists of multiple subgraphs, where each subgraph corre-sponds to either the generative feature or the output features from different levels of the detector backbone (referred to as discriminative features). The node features in each sub-graph represent multi-level information, corresponding to different feature levels. For graph computation, we propose the Inter-Mamba block and Cascade Knowledge Integration (CKI) strategy, which facilitate efficient knowledge fusion and propagation across subgraphs. The Inter-Mamba block is introduced to fuse the nodes of subgraphs between the generative feature and the low-level discriminative feature, here the c3 feature from CSPDarknet [1]. Then, a Cascade Knowledge Integration (CKI) strategy is proposed to propa-gate the knowledge from the low-level subgraph to the high-level subgraph in a cascade manner. During this cascading process, node features are updated using the Gate Recurrent Unit (GRU) method [9], while the VMamba block further refines these features across subgraphs. Our contributions can be summarized as follows: (1) We are the first to employ pseudo visible feature fine-grained fusion method for thermal object detection. The informa-tion interaction ability of graph at different granularities and the information selection and enhancement ability of Mamba have been fully utilized. (2) An Inter-Mamba block is proposed to facilitate cross-modality fusion between gen-erative and discriminative node features. Additionally, the cascade knowledge integration strategy aggregates knowl-edge from low-level to high-level feature subgraphs avoid-ing tedious computation. (3) Experiments conducted on public FLIR, LLVIP, and Autonomous Vehicles datasets demonstrate significant advantages over the state-of-the-art (SOTA) thermal object detection methods. 

# 2. Related Work 

2.1. Thermal Object Detection 

Thermal object detection is crucial in low-light environ-ments and privacy-sensitive scenarios. Existing approaches can be categorized into direct reconstruction and visible knowledge assistance . In the direct reconstruction ap-proach, the methods [21, 22, 38] focus on designing net-works to extract discriminative features by leveraging the intrinsic characteristics of thermal images. For example, GPCAnet [48] predicts object positions in the image to al-locate more ROIs to the predicted areas. The Visible knowl-edge assistance methods can be further divided into data augmentation and cross-modal transfer . The data augmen-tation works [2, 20] use GANs to convert visible images into thermal images, mixing them to enhance detector ro-bustness. In the cross-modal transfer approach, the works try to generate pseudo visual images or features. For ex-ample, TIRDet [44] uses Pearl-GAN for image translation. Xie et al [45] use a hallucination network to learn visible features from thermal images. All methods lack in-depth research on pseudo-visible information fusion. 6711 2.2. Graph Based Cross Modality Fusion 

In recent years, graph-based approaches have gained signif-icant traction in computer vision applications [36]. Typi-cally, graph operates as message-passing algorithms, where node representations are iteratively updated based on their neighbors through a differentiable aggregation function [34]. This makes graph particularly valuable in multi-source data fusion. For instance, Cai et al. [3] used a graph-attention mechanism to fuse embeddings from different fea-ture extractors, while Li et al. [24] proposed an interactive GNN-based architecture to facilitate cross-modality fusion. Our work is closely related latter work that utilizes graph structures to explicitly model and reason about different granularity information interactions between complemen-tary data sources. However, our approach uniquely incor-porates Mamba’s selection mechanism to strengthen graph node representations, effectively minimizing the impact of unimportant nodes at each step of hidden state computation. 

2.3. Mamba Based Cross Modality Fusion 

Since its inception for linear-time sequence modeling in natural language processing, Mamba [14] has rapidly been adapted for various applications in computer vision. For example, VMamba [35] leverages a four-way scanning al-gorithm to advance object detection and segmentation be-yond the capabilities of the Swin Transformer. Mamba has already been used in cross-modality fusion. Xie et al. [46] leveraged Mamba for dynamic feature enhancement in mul-timodal image fusion. Pan-Mamba [15] is developed to fa-cilitate efficient cross-modal information exchange and fu-sion. The Fusion-Mamba block [10] is introduced to miti-gate disparities between cross-modal features and enhance the consistency of fused feature representations. Addition-ally, Li et al. [23] proposed cross-modality fusion-Mamba, coupled with weather removal techniques, to improve de-tection accuracy under adverse weather conditions. Distinct from prior research, our work pioneers the integration of the Mamba architecture into graph representations for thermal object detection tasks, significantly enhancing graph em-beddings and processing capabilities.

3.2. Pseudo Visible Feature Fine-Grained Fusion 

For further integrating the generative feature z, a straight-forward attention-based fusion approach, as used in [44], can be employed. However, this method has limitations in effectively capturing high-level relationships among the features. Additionally, it struggles to capture essential vi-sual information due to the unreliability of the generated visible images, which often introduces a substantial amount of irrelevant information. To overcome these challenges, we introduce the Graph-Mamba Fusion (GMF) module as shown in Fig. 2(b). Graph structure is employed to estab-lish more compensated relationships between different level features, which Mamba is adapted to capture long-range de-pendencies with less computational complexity. To avoid getting lost in details, let’s first briefly intro-duce the process. (1) Graph construction. The features f 3,

f 4, f 5, and z are down-and-up sampled to different copies as graph nodes. Graph edges are constructed by comput-ing similarity between nodes, and message passing is per-formed by aggregating features from neighboring nodes. (2) Graph computation. An Inter-Mamba block is proposed to facilitate fusion between the nodes produced by latent fea-ture z and discriminative feature f 3 respectively as illus-trated in Fig. 2 (c). The GRU algorithm is used to up-date graph nodes, ensuring effective information propaga-tion. Subsequently, a VMamba block is used to further re-fine the node feature. The output g3 is formed by merging the node features of f 3 and is then multiplied with the nodes derived from f 4, enabling the fusion of information across different levels. The output g4 and g5 are obtained by merg-ing the node features from f 4 and f 5, respectively.

4.1. Experimental Settings 

Datasets. To evaluate our method, we conduct experiments on the FLIR-aligned dataset [49], LLVIP dataset [18], and Autonomous Vehicles dataset [42]. (1) The FLIR dataset originally presented challenges due to unaligned thermal-visible image pairs. Therefore, we utilize the aligned ver-sion, consisting of 5,142 thermal-visible image pairs, with 4,129 pairs for training and 1,013 for testing. This dataset includes three object categories: “person,” “car,” and “bicy-cle”. (2) The LLVIP dataset is collected in very dark en-vironments. It comprises 15488 aligned image pairs, with 12,025 pairs used for training and 3,463 pairs for testing. This dataset focuses on a single object class: “person”. (3) The Autonomous Vehicles dataset comprises 6,009 paired images for training and 1,503 for testing, covering five cat-egories: “bike”, “car”, “car stop”, “color cone”, and “per-son”. Compared to the FLIR and LLVIP datasets, the scenes in this dataset are more complex. 

Evaluation Metrics. We evaluate our method using standard object detection metrics [31], including mean Av-erage Precision (mAP), mAP50, and mAP75. The mAP metric represents the average AP over IoU thresholds rang-ing from 0.50 to 0.95, with an interval of 0.05. The mAP50 and mAP75 metrics correspond to the AP values at IoU thresholds of 0.50 and 0.75, respectively. Higher values for these metrics indicate better performance. 

Implementation Details. We utilize a pre-trained model on the COCO dataset and implement our approach using the MMDetection toolbox [6], a widely adopted framework for object detection. The network is trained using the SGD op-timizer with a batch size of 4 and an initial learning rate of 5e-4. The input image size is set to 640 × 640 for the FLIR, LLVIP, and Autonomous Vehicles datasets, with the training conducted over 8 epochs. The training process is conducted in two stages. In the first stage, the Pearl-GAN module is trained. In the second stage, with the parameters of the Pearl-GAN module fixed, the backbone, VMamba, Graph-Mamba Fusion (GMF) module, neck, and detection head are trained. For the GMF module, the number of graph nodes n is set to 3, and the number of message-passing iterations L is also set to 3. The cascade quantities of VMamba and Inter-Mamba blocks are each configured to 2. Details on hyper-parameter sensitivity are provided in the Appendix. To ensure reproducibility, all experiments are conducted with a random seed set to 0.

# 5. Conclusion 

In this paper, we proposed a novel cross-modal fusion method, termed Pseudo Visible Feature Fine-Grained Fu-sion (PFGF), for thermal object detection. The PFGF framework begins by constructing a graph which consists of several subgraphs. Each subgraph is generated from dif-ferent level output features from the backbone or synthetic visible feature. An Inter-Mamba block is then employed to facilitate cross-modality feature association between gener-ative and discriminative node features. Additionally, we in-troduce a Cascade Knowledge Integration strategy to prop-agate knowledge hierarchically from lower-level to higher-level subgraphs. In the process, VMamba is employed to further refine features. Extensive experiments demonstrate that our method achieves the SOTA performance.
