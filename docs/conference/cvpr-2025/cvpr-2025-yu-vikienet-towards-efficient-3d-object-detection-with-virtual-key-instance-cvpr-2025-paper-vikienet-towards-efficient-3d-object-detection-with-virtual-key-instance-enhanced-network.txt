# Abstract 

The sparsity of point clouds and inadequacy of semantic in-formation pose challenges to current LiDAR-only 3D object detection methods. Recent methods alleviate these chal-lenges by converting RGB images into virtual points via depth completion to be fused with LiDAR points. Although these methods have shown outstanding results, they often introduce significant computation overhead due to the high density of virtual points and noise due to inaccurate depth completion. Besides, they do not thoroughly leverage se-mantic information from images. In this work, we pro-pose the virtual key instance enhanced network (ViKIENet), a highly efficient and effective multi-modal feature fusion framework that fuses the features of virtual key instances (VKIs) and LiDAR points through multiple stages. Our con-tributions include three main components: semantic key instance selection (SKIS), virtual-instance-focused fusion (VIFF), and virtual-instance-to-real attention (VIRA). We also propose the extended version ViKIENet-R with VIFF-R which includes rotationally equivariant features. Experi-ment results show that ViKIENet and ViKIENet-R achieve significant improvements in detection performance on the KITTI, JRDB, and nuScenes datasets compared to existing works. On the KITTI dataset, ViKIENet and ViKIENet-R operate at 22.7 and 15.0 FPS, respectively. As of CVPR submission (Nov. 15 th , 2024), ViKIENet ranks first on the car detection and orientation estimation leaderboard, while ViKIENet-R ranks second (compared with officially pub-lished papers) on the 3D car detection leaderboard.

# 2. Related Works 

LiDAR-Only Object Detection. LiDAR-based 3D ob-ject detection has been studied extensively, particularly on a voxel-based approach due to its ability to balance between efficiency and accuracy. Sparsity-based algo-rithms [5, 11, 16, 36] have been proposed to handle sparse features. VoxelNet introduces VFE to learn unified feature representations of 3D voxels [45], while SECOND imple-ments a highly efficient sparse convolution method to accel-erate 3D convolution [36]. PV-RCNN exploits the benefits of voxel-based and point-based methods to obtain highly discriminative features [24]. Recently, Voxel-RCNN estab-lished that high-performance detection can be achieved us-ing voxel-based approaches without relying on precise lo-calization of raw points [3]. PDV [9] leverages point den-11845 sity and distance correlation to enhance voxel-based 3D de-tection. However, the sparsity caused by the low scanning resolution of LiDARs poses limits in the detection results especially for distant, obstructed, or small objects. 

Multi-modal Object Detection. To enhance the perfor-mance of 3D object detection, researchers have jointly uti-lized RGB images and LiDAR point clouds. SparseFu-sion [34] fuses sparse LiDAR and camera proposals via cross-modality attention for efficient and accurate 3D detec-tion. Although point-based fusion methods such as Point-Painting [27] append semantic scores from images to Li-DAR points as additional features, they do not address the issue of point cloud sparsity. Recent approaches ad-dressed this problem by leveraging depth completion net-works that generate dense virtual points from RGB images and have achieved remarkable performance in 3D object detection [31–33]. However, virtual points are often noisy and they introduce expensive computation costs. Although there have been recent works for accelerating computations on dense virtual points via random downsampling or by discarding nearby redundant voxels [32], these approaches still require operations over a substantial number of virtual points within a 3D space. In this work, we address this issue by proposing SKIS to generate VKIs. 

Feature Fusion Strategies. BEVFusion projects features from images and LiDAR points onto a shared BEV space, enabling spatial feature alignment and interaction [15, 18]. IS-Fusion [39] introduces instance-scene collaborative fu-sion to improve BEV-based 3D detection, going beyond conventional scene-level fusion methods. SFD, on the other hand, fuses virtual point and LiDAR point features dynam-ically at the grid level [33], while CLOCs perform feature fusion through result-level prediction [20]. However, exist-ing fusion strategies regard the two modalities as features of similar nature—they do not consider the imbalance and inconsistency between these two sets of features during the fusion process, resulting in them being ineffective when ap-plied to the fusion of VKIs. We propose VIFF and VIRA for more intelligent feature fusion between the two modalities. 

Rotation and Transformation Equivariant 3D Object Detection. Recent works [8, 31, 32, 42] have proposed ro-tation and/or reflection equivariant feature processing tech-niques to improve the accuracy and robustness of 3D ob-ject detection. EON [42] was proposed to leverage object-level equivariance and TED [31] was proposed to obtain transformation-equivariant 2D BEV and 3D voxel features before aggregating these features for region proposal and bounding box refinement. EON’s [42] approach requires identifying object-level features hence they compute equiv-ariant features up to an intermediate stage during seed fea-ture extraction and then decompose these features, which are believed to be object-level, into orientation hypotheses and invariant geometry features, after which, only the ge-ometry features are aggregated for proposals. We propose a more certain and efficient object-level equivariant feature extraction by identifying key instances first with image seg-mentation. TED [31] and Virconv-T [32] apply equivari-ant features from the entire virtual point clouds, resulting in significant computation overhead. To address this issue, we propose the ViKIENet-R variant, which applies feature ex-traction only on VKIs utilizing sparse convolution but still provides significant performance gain. 

# 3. Methodology 

3.1. Overview of Proposed ViKIENet Framework 

Fig. 2 illustrates our proposed framework with its input be-ing RGB images and point clouds. SKIS first generates a corresponding depth map and a semantic segmentation mask from the RGB image concurrently. These results are then combined to obtain semantically enriched VKIs.The VKIs and LiDAR points are subsequently voxelized in two separate branches and 3D sparse convolution is applied to extract 3D features [36]. During this process, the VIRA module performs feature interaction and alignment between virtual points’ features and LiDAR points’ features within those instances. Thereafter, VIFF is applied for feature fu-sion via two parts: one for fusing BEV features and the other for fusing RoI features. The VIFF module first con-verts the 3D features from both branches into BEV repre-sentations. A 2D backbone followed by region proposal networks (RPN) are then applied to generate initial region proposals [3]. Subsequently, the RoI features are extracted from the 3D features by voxel RoI pooling [3] before a cross-modal fusion is performed. Finally, the fused RoI fea-tures are exploited in the detection head for further bound-ing box refinement, leading to the final detection results. 

3.2. Semantic Key Instance Selection Module 

The SKIS module generates semantically enriched VKIs to reduce the computational load associated with dense virtual points while leveraging their semantic information. These key instances, in turn, serve as input from the camera branch to be fused with the LiDAR branch at a later stage. With reference to SKIS in Fig. 2, a depth completion model [10] is applied to get a corresponding depth map of the input image, and a semantic segmentation model [41] is applied to obtain the semantic class and score of each pixel of the same image. Having 3D coordinates, the pix-els of key instances are then converted into virtual points in the 3D space. Similar to PointPainting [27], the semantic scores are appended to these virtual points, forming VKIs which also encapsulate rich semantic information from im-ages. Furthermore, our approach addressed a problem in PointPainting [27] where no corresponding LiDARs points can be found to paint on. 11846 Formally, defining W and H as the width and height of the input RGB image, respectively, the segmentation mask as Iseg ∈ RW ×H , and the corresponding depth map as

3.3. Virtual Instance Focused Fusion Module 

The proposed VIFF module comprises two aspects of the fusion strategies: BEV feature fusion and RoI feature fu-sion. They are designed to fuse the features of VKIs with those of LiDAR points across multiple dimensions, com-bining information holistically from two different sensors. We leverage the dense and rich features brought about by the VKIs to achieve increased accuracy for the region pro-posals (where LiDAR points are sparse) and to reduce the impact of noise in virtual points onto region proposals. To this end, VIFF employs a thorough and effective fusion ap-proach within the BEV space [15], enhancing features and highlighting the key regions at both channel and spatial lev-els. Herein lies two key challenges in the RoI feature fusion: (i) the significant differences in modality between the VKIs and LiDAR point cloud features (since VKIs lack the con-textual information around the instances compared to the complete set of virtual points), causing inadequacy for fea-ture representation in bounding box refinement; and (ii) the significant discrepancy of VKI depth information and that of LiDAR points, resulting from inaccurate depth comple-tion (compared to LiDAR) of virtual points that persist in state-of-the-art models [29, 37]. To address these issues, VIFF adopts a cross-modal approach to provide a more ac-curate and effective feature fusion strategy. With reference to Fig. 2, voxelization and 3D sparse con-volution are applied on VKIs and LiDAR point clouds [36, 45], with VIRA (which will be explained in the next sec-tion) employed subsequently to refine the VKIs’ features. 3.4. Virtual-Instance-to-Real Attention Module 

To mitigate the impact of inaccurate depth information of VKIs in the fusion process, we propose the virtual-instance-to-real attention (VIRA) module for preparatory 3D feature adjustments, as shown in Fig. 4. We leverage the precise depth measurements from the associated LiDAR points to refine the raw noisy features of the VKIs. This is achieved via a cross-attention mechanism between the two feature modalities, which, in turn, produces more accurate and reli-able feature representations of the VKIs. Despite being beneficial in determining the regions of the LiDAR point clouds that VKIs should focus on, fea-ture search within a 3D space is non-trivial. This is because using 3D index or distance-based search to locate LiDAR features associated with VKI features will be erroneous due to the extensive depth discrepancies between virtual points’ and LiDAR points’ features. Therefore, we utilize the voxel indices of the sparse 3D features from both modalities to project their coordinates onto a shared 2D camera image domain using a projection function denoted as π(x). For each VKI feature, we resort to its 2D location IV in the im-age to identify the corresponding LiDAR features FL(xj )

# 4. Experiment Results 

4.1. Dataset and Evaluation Metrics 

We evaluate our proposed ViKIENet on the KITTI [4] dataset, the nuScenes dataset [1], and the JRDB [19] dataset. The KITTI object detection benchmark consists of 7481 training and 7518 testing samples [4]. The train-ing samples are further divided into a train-validate split of 3712-3769. A 3D average precision (AP) under 40 re-call thresholds (R40) is used as the evaluation metric for the KITTI dataset with IoU thresholds set at 0.7, 0.5, and 0.5 for cars, pedestrians, and cyclists, respectively. The nuScenes dataset contains approximately 1.4M camera images, 390k LIDAR sweeps, and 1.4M object bounding boxes in 40k keyframes [1]. We used the standard evaluation kit pro-vided by nuScenes to calculate the mAP. The KITTI dataset also contains depth completion tasks with dense depth la-bels provided [26] while the other two datasets do not. Considering classic depth completion methods can achieve decent results at close range without requiring depth labels for training [12], we chose the JRDB dataset [19], which has a relatively shorter horizontal range, to validate the generalizability of our proposed model across different environments and scenarios and to provide detection solu-tion for mobile robots. JRDB is a large-scale multi-modal dataset collected in both indoor and outdoor environments, featuring crowded human scenes [19], with 3D annotations for pedestrians provided. We randomly selected 7 out of 27 training sequences as the validation split. Similar to KITTI, it sets 0.3 as the 3D IoU threshold for pedestrians. 

4.2. Setup Details 

For fair comparisons, we employed the same pre-trained depth completion model, PENet [10], as SFD [33] and VirConv [32]. It predicts a dense depth map from the input color image with accurate yet sparse LiDAR depth measurements [10]. For semantic segmentation, we used the BiSeNet V2 model for maximum efficiency as it can achieve 156 FPS for 1024 ×512 inputs on a GeForce 1080Ti GPU [41].On the KITTI dataset, we adopted the same de-tection range, voxel size, and maximum number of points per voxel as those used in VirConv-L [32]. We employed data augmentation methods such as ground-truth sampling, local transformations (rotation and translation), and global transformations (rotation and flipping) [23, 30, 33], and same loss functions as VirConv-L [32]. For ground-truth sampling, we also appended nclass dimensions for scores. We trained and tested our models on an Nvidia GeForce RTX 3090 GPU for forty epochs with a batch size of four and an initial learning rate of 0.01 with a one-cycle learning rate scheduler. During training, we used an NMS threshold of 0.8 to generate 160 object proposals. # 5. Conclusion 

We present a LiDAR and camera feature fusion network ViKIENet, including a SKIS module, a VIFF module, and a VIRA module; and an extended version ViKIENet-R that includes rotational-transformation equivariant features. Our approach significantly lowers computational cost with im-proved 3D object detection accuracy compared to existing baselines.
