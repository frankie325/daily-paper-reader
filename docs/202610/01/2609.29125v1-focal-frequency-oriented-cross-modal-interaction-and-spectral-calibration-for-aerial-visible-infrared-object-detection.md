## 摘要
在航空RGB-IR目标检测中，有效利用跨模态互补信息对于复杂光照和环境条件下的鲁棒感知至关重要。现有基于多模态的检测器主要关注空域交互或特定频率特征增强，而不同频率分量的跨模态交互模式仍未得到充分探索。此外，光谱差异本身可能既包含有用的互补线索，也包含不可靠的模态特有响应，使得不加区分的频率融合并非最优。为解决这些问题，我们提出FoCal，一个面向频率的航空RGB-IR目标检测框架。首先，设计了一种频率感知双域校准（FADC）模块，以显式建模频率相关的跨模态交互。低频分量被协同整合为共享结构共识，而高频分量通过选择性跨模态交换保留模态特有信息。得到的频率感知线索进一步传递到原始特征域以调节跨模态校准。其次，引入差异引导频谱调制（DGSM）模块，该模块使用置信加权相对幅度差异来刻画跨模态频谱不平衡，并将其转换为有界符号门控，用于对联合多模态频谱进行自适应增强、保留或衰减。在DroneVehicle、ESCVehicle和ATR-UMOD上的大量实验证明了FoCal的有效性，分别取得83.5%、54.8%和64.6%的mAP50值。同时，仅用3.0M参数，FoCal达到113.6 FPS，同时保持领先的检测精度，展现出良好的精度-效率权衡。代码可在 https://github.com/universeliang/FoCal 获取。

## Abstract
In aerial RGB--IR object detection, effectively exploiting complementary information across modalities is critical for robust perception under complex illumination and environmental conditions. Existing multimodal detectors mainly focus on spatial-domain interaction or frequency-specific feature enhancement, while the cross-modal interaction patterns of different frequency components remain insufficiently explored. Moreover, spectral discrepancy itself may contain both useful complementary cues and unreliable modality-specific responses, making indiscriminate frequency fusion suboptimal. To address these issues, we propose FoCal, a frequency-oriented framework for aerial RGB--IR object detection. First, a Frequency-Aware Dual-Domain Calibration (FADC) module is developed to explicitly model frequency-dependent cross-modal interaction. Low-frequency components are collaboratively consolidated into a shared structural consensus, whereas high-frequency components preserve modality-specific information through selective cross-modal exchange. The resulting frequency-aware cues are further transferred to the original feature domain to regulate cross-modal calibration. Second, we introduce a Discrepancy-Guided Spectral Modulation (DGSM) module, which characterizes cross-modal spectral imbalance using confidence-weighted relative amplitude discrepancy and transforms it into a bounded signed gate for adaptive enhancement, preservation, or attenuation of the joint multimodal spectrum. Extensive experiments on DroneVehicle, ESCVehicle, and ATR-UMOD demonstrate the effectiveness of FoCal, yielding $\mathrm{mAP}_{50}$ values of 83.5\%, 54.8\%, and 64.6\%, respectively. Meanwhile, with only 3.0M parameters, FoCal achieves 113.6 FPS while preserving leading detection accuracy, highlighting a favorable accuracy--efficiency trade-off. - **背景动机**：可见光（RGB）成像依赖光照，在低照度、强光干扰、恶劣天气下会严重退化；红外（IR）成像感知热辐射，对光照不敏感，能补充物体轮廓与结构线索。因此，RGB–IR 融合成为实现全天候鲁棒视觉感知的有效范式。
- **现有研究的不足**：
  - 大多数现有融合检测器主要在**空间域**做跨模态交互（如注意力聚合、特征对齐），未显式区分结构信息与模态特异细节。
  - 近年来出现基于**频域分解**的方法，但这些方法主要关注“分解后如何对不同频段分别做增强处理”，而忽略了更根本的问题——**不同频段的跨模态交互模式本身是否应当不同**。
  - 另外，光谱差异本身同时包含“有用互补线索”和“不可靠的模态特有响应”，无差别地做频率融合可能是次优的。
- **本文整体含义**：提出 **FoCal** 框架，核心思想是**频率特性不仅决定后续处理算子，更应决定跨模态信息流的拓扑结构**；同时把频谱差异作为“控制信号”而非“内容信息”，以避免放大模态特有噪声。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体架构
FoCal 基于双流多模态检测框架（扩展自 Ultralytics 单模态框架），包含两个核心模块：
- **FADC**（Frequency-Aware Dual-Domain Calibration，频率感知双域校准）
- **DGSM**（Discrepancy-Guided Spectral Modulation，差异引导频谱调制）

### 2.2 FADC 模块
**核心思想**：频率特异性不仅决定后续处理算子，更决定跨模态交互的**信息流拓扑**。

**具体流程**：
1. **频率分解**：对 RGB 和 IR 特征 \(X_{rgb}, X_{ir} \in \mathbb{R}^{C\times H\times W}\) 使用 Haar 小波变换（DWT），分解为 1 个低频近似分量 \(A\) 和 3 个方向高频分量 \(H^h, H^v, H^d\)。将 3 个方向高频分量合并为 \(H_m\)（\(m\in\{rgb,ir\}\)）。
2. **低频——共识形成**：低频分量主要编码粗轮廓、物体布局和大尺度结构，跨模态对应性较强。因此采用**多对一交互拓扑**：将两模态低频分量拼接，经轻量卷积门控和 Softmax 得到互补权重 \(\eta_{rgb}, \eta_{ir}\)，形成共享结构锚点 \(A_{shared} = \eta_{rgb}\odot A_{rgb} + \eta_{ir}\odot A_{ir}\)（权重和为 1）。这避免了固定平均，允许网络根据局部观测质量动态调整贡献。
3. **高频——选择性交换**：高频分量包含模态特有边缘/纹理，也可能含有传感器噪声，过早合并会抑制有用细节或传播不可靠响应。因此采用**二对二交互拓扑（保留个体性的选择性交换）**：对每个模态用通道平均池化和最大池化得到空间描述符，联合编码后经卷积-Sigmoid 门控生成**接收偏好掩码** \(M_{rgb}\) 和 \(M_{ir}\)，再更新为 \(\tilde{H}_{rgb}=H_{rgb}+M_{rgb}\odot H_{ir}\)，\(\tilde{H}_{ir}=H_{ir}+M_{ir}\odot H_{rgb}\)。每个模态保留自身高频响应，同时有选择地吸收对方互补细节。注意 \(M_{rgb}\) 刻画的是“目标模态的接收偏好”而非“源模态的显著性”，这是前向接收端条件下的交互。
4. **频率条件特征重组**：\(\tilde{X}_{rgb}=A_{shared}+\tilde{H}_{rgb}\)，\(\tilde{X}_{ir}=A_{shared}+\tilde{H}_{ir}\)。两模态共享同一低频结构锚点，但各自保留经过校准的高频细节。
5. **频率引导可靠性校准**：频率条件特征不作为最终融合输出，而是用于估计原始特征流之间“何处、何种信息可以可靠迁移”。由 \(\tilde{X}_{rgb},\tilde{X}_{ir}\) 生成空间与通道可靠性掩码 \(W_s, W_c\)，融合得 \(W\)；同时联合编码原始双模态得到联合先验 \(O_{joint}\)；组合得模态特有校准掩码 \(R_k = O_{joint}\odot W_k\)，然后注入互补信息：\(X_k^{aug}=X_k+R_k\odot X_{\bar{k}}\)。最后通过可靠性参考特征 \(X_k^{ref}=X_k^{aug}\odot R_k\) 及残差校准 \(X_k^{out}=\sigma(\Delta X_k)\odot X_k^{aug}+X_k^{ref}\) 完成输出。

### 2.3 DGSM 模块
**核心思想**：**将频谱差异作为“控制信号”而非“内容”**，实现对联合频谱的自适应“增强、保留或衰减”。

**具体流程**：
1. **映射与变换**：RGB 与 IR 特征经共享投影 \(P(\cdot)\) 映射到公共比较空间，再做 FFT 得 \(Z_{rgb}, Z_{ir}\)，计算幅度谱 \(A_{rgb}, A_{ir}\)。
2. **置信度加权相对幅度差异**：定义相对差异 \(D_{rel} = \frac{|A_{rgb}-A_{ir}|}{A_{rgb}+A_{ir}+\epsilon}\)。为避免“两个几乎不活跃的频谱响应因分母过小而产生大差异”的问题，引入能量置信项：\(A_\Sigma=A_{rgb}+A_{ir}\)，能量 \(E=\frac{A_\Sigma}{\text{Mean}_\Omega(A_\Sigma)+\epsilon}\)，置信度 \(C_e=\frac{E}{1+E}\)。最终差异描述符 \(D=D_{rel}\odot C_e\)。
3. **将差异转化为有界符号门控**：\(G_d=\tanh(\mathcal{G}_d(D))\)，\(G_d\in[-1,1]\)，其中 \(\mathcal{G}_d\) 为轻量 1×1 卷积。这允许模型学习对差异的不同响应，差异本身不被假设为天生有信息性。
4. **联合频谱调制**：并行地，将原始 RGB/IR 拼接并投影为紧凑联合表示 \(X_{joint}\)，做 FFT 得 \(Z_{joint}\)，然后做有界残差调制 \(Z_{mod}=Z_{joint}\odot(1+\gamma G_d)\)（\(\gamma=0.5\)）。之后将调制谱实部/虚部拼接，经轻量谱变换 \(\Phi(\cdot)\)（残差方式）处理，再逆 FFT 回空间域，最后投影回原始维度并与拼接输入做残差连接。

### 2.4 冗余削减策略（RR）
- 双流分支保留到 P4，P5 由融合后 P4 经无参数下采样和高级语义编码共享构建，避免重复深层特征提取。
- 采用紧凑的两尺度预测层次（P4、P5），P3 参与双向多尺度聚合但不作为最终预测层。
