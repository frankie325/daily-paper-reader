## 摘要
遥感图像中的视觉定位旨在定位由指代表达式描述的目标。现有大多数方法预测水平边界框，对于任意朝向的目标往往不够准确。为了解决这一局限，我们提出了 O²-VG，一组面向旋转目标视觉定位的模型，包含三种互补设计。具体来说，O²-VG-Trans 是一种用于旋转目标视觉定位的跨模态 Transformer，为该模型家族建立了强大的判别基础。在其基础上，O²-VG-Uni 无需特定文本提示即可为可能的前景目标预测通用旋转候选框，并支持通过缓存的候选框嵌入进行目标检索。利用这些通用旋转候选框作为输入提示，O²-VG-VLM 是一种自回归视觉语言模型，通过多 token 预测并行生成旋转框 token 块。此外，我们构建了 DIOR-R-RSVG，一个用于遥感图像旋转目标视觉定位的数据集，提供图像、指代表达式和旋转框三元组用于训练和评估。总之，O²-VG 家族提供了一个灵活的框架，涵盖判别式 Transformer 和生成式视觉语言模型，在多个基准上取得了优越性能。代码可在 https://github.com/wokaikaixinxin/ai4rs 获取。

## Abstract
Visual grounding in remote sensing images aims to locate objects described by referring expressions. Most existing methods predict horizontal bounding boxes, which are often inaccurate for objects with arbitrary orientations. To address this limitation, we introduce O$^2$-VG, a family of models for oriented object visual grounding with three complementary designs. Specifically, O$^2$-VG-Trans is a cross-modality transformer for oriented object visual grounding. It establishes a strong discriminative foundation for the model family. Building upon it, O$^2$-VG-Uni predicts universal oriented proposals for possible foreground objects without specific text prompts. It also supports object retrieval through cached proposal embeddings. Using these universal oriented proposals as input prompts, O$^2$-VG-VLM is an autoregressive vision-language model. It generates oriented box token blocks in parallel through multi-token prediction. In addition, we construct DIOR-R-RSVG, a dataset for oriented object visual grounding in remote sensing images. It provides image, expression, and oriented box triplets for training and evaluation. Together, the O$^2$-VG family provides a flexible framework that spans discriminative transformers and generative vision-language models. It achieves superior performance across multiple benchmarks. Code is available at https://github.com/wokaikaixinxin/ai4rs.

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

论文提出了一个模型家族，包含三个互补模型：

### 2.1 O²-VG-Trans：旋转目标视觉定位跨模态 Transformer

- **图像编码**：使用 ResNet 提取多尺度特征，经 Channel Mapper 投影到 256 维，获得 4 个尺度特征图（stride 8/16/32/64）。
- **文本编码**：使用冻结的预训练 BERT 编码指代表达式，并采用子句级注意力掩码，得到 256 维文本特征。
- **跨模态编码器**：6 层堆叠，视觉与文本特征先经双向注意力交互，再分别经可变形注意力（视觉）和自注意力（文本）细化。
- **语言引导的查询选择**：计算视觉与文本的余弦相似度矩阵，选 top-K（K=900）候选旋转参考框和可学习查询。
- **跨模态解码器**：6 层，查询依次经过自注意力、文本交叉注意力、旋转可变形注意力（采样点围绕旋转框中心旋转）和前馈网络。
- **损失函数**：包含对比分类损失（Focal Loss）、L1 回归损失和 KLD 损失，权重分别为 1.0、5.0、2.0。

### 2.2 O²-VG-Uni：通用旋转候选框生成器

- **两阶段训练**：
  - 阶段 1：冻结文本编码器（RemoteCLIP），只训练视觉分支，通过对比学习对齐视觉与语言。
  - 阶段 2：冻结视觉分支，用可学习的 **objectness prompt**（仅 512 维）替代文本编码器，提取任意类别的前景对象候选。
- **图像编码**：采用 ResNetvd，提取 3 个尺度特征（stride 8/16/32），少于 Trans 的一个特征层。
- **混合编码器**：顶层特征做自注意力，多尺度特征经 CNN 融合，只处理图像模态。
- **查询选择**：根据视觉特征与类别文本（阶段 1）或 objectness prompt（阶段 2）的相似度，选 top-K（K=300）旋转参考框与查询。
- **对象检索**：缓存旋转候选框嵌入，利用 RemoteCLIP 文本嵌入进行余弦相似度检索，无需重新推理。

### 2.3 O²-VG-VLM：多 token 预测的视觉语言定位模型

- **架构**：Moon-ViT 视觉编码器（27 层，1152 维）→ MLP 投影到 2048 维 → Qwen2.5 语言解码器（36 层，2048 维）。
- **旋转框 token 化**：将 `(cx, cy, w, h, θ)` 离散化到 1000 个 bin，形成固定长度的 **旋转框 token 块**（共 5 个坐标 token + 2 个特殊 token）。
- **多 token 预测（MTP）**：每个块固定 7 个 token，块内采用双向注意力并行预测，块间保持因果顺序，提升解码效率。
- **损失与推理**：联合使用 NTP 与 MTP 损失；提供三种推理模式：
  - **Slow Mode**：纯 NTP 逐 token 自回归；
  - **Fast Mode**：纯 MTP 并行生成块；
  - **Hybrid Mode**：默认 MTP，检测到无效框结构时切换回 NTP 解码该块，平衡速度与鲁棒性。
- **输入提示**：将 O²-VG-Uni 生成的通用旋转候选框作为文本提示，辅助定位。

### 2.4 DIOR-R-RSVG 数据集

- **来源**：图像和指代表达式来自 DIOR-RSVG；旋转框标注来自 DIOR-R；通过类别与图像一致性进行自动 IoU 匹配，再人工校验。
- **规模**：17,402 张 800×800 图像，38,320 个指代表达式（20 类目标），划分 26,991 / 3,829 / 7,500（train/val/test）。
- **特点**：包含旋转框与指代表达式三元组，目标具有大长宽比、任意角度、尺度变化大。

## 6. 论文的主要结论与发现

- **O²-VG-Trans** 在三个数据集上均优于 Rotated GiT-B、Rotated GDINO、Rotated EGDINO，验证了跨模态 Transformer 和旋转可变形注意力的有效性。

- 整体上，O²-VG 家族统一了判别式与生成式范式，为遥感旋转目标视觉定位提供了有效且灵活的解决方案。
