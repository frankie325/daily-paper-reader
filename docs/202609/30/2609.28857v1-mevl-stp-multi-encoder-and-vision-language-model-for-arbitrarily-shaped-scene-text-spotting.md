## 摘要
场景文本检测与识别对于自然图像中弯曲标志、密集多方向字符等任意形状文本实例仍具挑战性，紧耦合架构会将定位误差直接传播为识别失败。我们提出了一种两阶段流程，将多编码器分割与视觉语言模型识别相结合以解决这一问题。在检测阶段，六个冻结的视觉编码器（CLIP、DINOv2、SigLIP、EVA-CLIP、SAM和ConvNeXt）提取涵盖语义、空间和纹理谱的互补特征，这些特征通过带通道注意力的可训练层次化特征金字塔网络融合，并经深度监督的渐进尺度扩展网络解码，生成精确的实例级文本掩码。通过保持编码器冻结，其独立学习到的特征空间在融合时保持正交，避免了单骨干检测器中导致边界精度下降的特征同质化。检测阶段生成紧贴弯曲和任意方向文本实际形状的多边形掩码，而非不可避免地包含背景内容的轴对齐矩形。在识别阶段，这些多边形掩码裁剪图像将目标文本与周围杂乱背景隔离开来，使经低秩适配（Low-Rank Adaptation）在多边形裁剪场景文本上微调的Qwen3-VL-8B-Instruct模型能够专注于阅读文本，不受邻近单词或背景噪声干扰。在未使用任何合成预训练数据的情况下，我们的方法在CTW1500上取得了91.99%的检测F值和85.86%的端到端H-mean，达到了新的最优水平，并在Total-Text和ICDAR 2015上取得了强劲性能，且未使用任何合成训练数据。代码见 https://github.com/doubleblind-afk/MEVL-STP。

## Abstract
Scene text spotting remains challenging for arbitrarily shaped text instances such as curved signs and dense multi-oriented characters in natural images, where tightly coupled architectures propagate localization errors directly into recognition failures. We present a two-stage pipeline that combines multi-encoder segmentation with vision-language model recognition to address this problem. In the detection stage, six frozen vision encoders (CLIP, DINOv2, SigLIP, EVA-CLIP, SAM, and ConvNeXt) extract complementary features spanning semantic, spatial, and texture spectra, which are fused through a trainable hierarchical Feature Pyramid Network with channel attention and decoded via a deep-supervision Progressive Scale Expansion network to generate precise instance-level text masks. By keeping the encoders frozen, their independently learned feature spaces remain orthogonal during fusion, preventing the feature homogenization that degrades boundary precision in single-backbone detectors. The detection stage produces tight polygon masks that conform to the actual shape of curved and arbitrarily oriented text, rather than axis-aligned rectangles that inevitably include background content. In the recognition stage, these polygon-masked crops isolate the target text from surrounding clutter, allowing a Qwen3-VL-8B-Instruct model, fine-tuned via Low-Rank Adaptation on polygon-cropped scene text, to focus purely on reading the text without interference from neighbouring words or background noise. Without any synthetic pretraining data, our method achieves 91.99% detection F-measure and 85.86% end-to-end H-mean on CTW1500, setting a new state of the art and achieving strong performance on Total-Text and ICDAR 2015 without any synthetic training data. Code is available at https://github.com/doubleblind-afk/MEVL-STP

- **研究背景**：场景文本检测与识别（text spotting）在自动驾驶、增强现实、文档理解等领域有广泛应用，但任意形状文本（如弯曲标志、密集多方向字符）仍然极具挑战。

- **整体含义**：论文提出一种**解耦的两阶段框架 MEVL-STP**，将“多编码器分割检测”与“视觉语言模型识别”结合，通过高精度多边形掩码隔离文本区域，避免背景干扰，从而提升任意形状场景文本的检测与识别性能，并在不使用合成数据的情况下达到新 SOTA。

## 2. 论文提出的方法论

### 2.1 总体架构
- 两阶段流水线：**Stage 1** 多编码器集成 + 渐进尺度扩展（PSE）进行实例级文本检测；**Stage 2** 微调视觉语言模型（VLM）进行文本识别。

### 2.2 检测阶段：多编码器特征提取与融合
- **六个冻结的视觉编码器**：CLIP、SigLIP、EVA-CLIP（语义谱）、DINOv2、SAM（空间谱）、ConvNeXt（纹理谱）。
- **互补特征**：语义编码器捕获“文本是什么”，空间编码器捕获“文本边界在哪里”，纹理编码器保留局部笔画模式。
- **融合方式**：各编码器输出投影到 `d=512` 维，经 1×1 卷积后在三个金字塔尺度（8²、16²、32²）上拼接融合：

  \[
  F_l = \text{Conv}_{1\times1}\left(\text{Concat}\left(\text{Proj}_i(f_i)\right)_{i=1}^{6}\right),\quad l\in\{1,2,3\}
  \]

- **可变形注意力**：在 FPN 中引入 Deformable Attention（3 个尺度、8 个采样点、8 个头），仅在任务相关位置采样特征。
- **局部手工特征**：额外提取 16 通道（Gabor、Sobel、笔划宽度、CLAHE、局部方差、边缘密度、梯度幅度等），经卷积分支处理到 512 通道后与 FPN 输出拼接，形成 `F_comb ∈ R^{1024×32×32}`，用于锐化多边形边界。

### 2.3 检测解码：渐进尺度扩展（PSE）
- PSE 预测 `K=6` 个尺度逐渐增大的核图，最小核捕获文本中心，后续核向外扩展但不合并相邻实例。
- 解码流程：最小核 S1 以阈值 0.4 二值化并做连通域标记；后续核（阈值 0.5）通过广度优先搜索扩展，保留实例边界；丢弃轮廓小于 50 像素的实例；用 Douglas-Peucker 算法（ε=0.002×周长）简化多边形。
- **解耦特征交互**：论文用能量描述公式（\(E_{\text{total}} = E_{\text{semantic}} + E_{\text{spatial}}\)）定性说明语义特征提供“扩张力”，空间特征提供“停止力”，冻结编码器保持特征空间正交，避免单骨干中的特征同质化。

### 2.4 识别阶段：VLM + LoRA
- **骨干模型**：Qwen3-VL-8B-Instruct。
- **参数高效微调**：对 query、key、value、output 投影应用 Low-Rank Adaptation（LoRA），秩 `r=16`，α=32，dropout 0.05，仅训练约 0.2% 参数。
- **输入准备**：从多边形标注裁剪文本，填充 5 像素，保持长宽比缩放至 256×256 画布，白色背景填充。
- **训练损失**：仅对助手回复 token 计算选择性交叉熵：

  \[
  L_{\text{rec}} = -\frac{1}{|A|}\sum_{i\in A}\log P(y_i\mid y_{<i}, x)
  \]

### 2.5 端到端训练策略
- **三阶段训练**：
  - Phase 1（epoch 1–2）：仅训练检测（\(\lambda_{\text{rec}}=0\)）。
  - Phase 2（epoch 3–10）：每 16 步引入 VLM 稀疏监督，\(\lambda_{\text{rec}}=0.2\)，每批 1 个裁剪。
  - Phase 3（epoch 11–30）：每 8 步，\(\lambda_{\text{rec}}=0.4\)，每批 2 个裁剪。
- **学习率**：检测 `lr_det=1e-4`，VLM `lr_vlm=1e-5`；有效批次大小 16（8×2 累积）；bfloat16。
- **总损失**：\(L = L_{\text{det}} + \lambda_{\text{rec}}L_{\text{rec}}\)，其中 \(L_{\text{det}} = L_{\text{BCE}} + L_{\text{Dice}}\)。

## 6. 论文的主要结论与发现

- 六个编码器融合的互补特征显著提升检测性能，单一特征谱均不足以完成任务：语义编码器单独 F1 仅 0.32%，空间编码器单独 72.88%，三者结合达 91.99%。
- 空间编码器（SAM、DINOv2）对检测贡献最大；移除 SAM 使 F1 下降 7.92，移除 DINOv2 下降 4.05，而语义/纹理编码器损失较小。
- 联合训练检测与识别会导致性能崩溃（H-mean 56.85%），分阶段训练可恢复至 85.86%，验证了解耦训练的必要性。

- 无需合成预训练数据，在 CTW1500 上检测 F1 92.0%，端到端 H-mean 85.9%（Full）和 75.2（None），刷新 SOTA；在 Total-Text 和 ICDAR 2015 上也取得有竞争力的结果。
